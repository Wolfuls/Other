更新：2026年10月23日

遊び方
index.html をChrome / Edge等で開いてください。
HTML・JavaScript・CSS・assetsフォルダーを同じ構成で置きます。
画像は assets/miload-motion-v2.png の外部PNGです。HTMLへの画像埋め込みはありません。
インストールやネット接続は不要です。保存機能はありません。

操作
← / → または A / D：横移動
W / ↑：ジャンプ。押す長さで高さを調整。
Space：ドアの前で次のエリアへ。それ以外ではジャンプ。
マウス移動：照準。360度、カーソルの方角に弾を飛ばせます。体と杖は照準では回転しません。
左クリック：魔法。押しっぱなしで連射。
マウスホイール：ゲーム画面上で所持杖を切り替え。
E：杖・月のハートを拾う。所持杖が2本なら交換する枠を選択。
Esc：一時停止。交換中はキャンセル。
キーボードの補助操作：Z / Jで魔法、Qまたは1 / 2で杖切替。
マウス未操作時は向いている方向へ発射。タッチボタン操作も同様です。
お菓子は触れた瞬間に食べます。食事ボタンはありません。
右上の♪で効果音をオンにできます。

・W / ↑でジャンプ、ドア前のSpaceでエリア移動、外部PNGのファイル構成を継続。

中心ルール
・敵HPを魔法で0にすると5秒間お菓子に変身。接触して食べると撃破確定。
・5秒過ぎると敵がHP全回復して復活。ボスも同じルール。
・初期ライフ2ハート、初期装備は星くずの杖1本。
・魔法は共通エネルギーを消費し、時間で回復。切替やステージ移動ではリセットされません。
・幸福度100%で1ハート回復して0%。満タン時は99%まで。
・被弾しても幸福度は減りません。99%で被弾しても自動回復せず、次のお菓子で回復します。
・所持できる杖は2本。交換した杖は地面に残り、再取得可能。
・ライフ、最大ライフ、幸福度、杖は次のステージへ引き継ぎ。
・死亡でラン終了。次のランは初期状態から。残機・倉庫・途中復帰はありません。
・全3ステージ。最終ボスをお菓子にして食べるとクリア。

仮設定
舞台：月あかりの森 / 硝子の庭園 / 真夜中の城
お菓子：小1% / 中5% / 大12%
エネルギー：最大100、毎秒18回復（射撃中も回復）
1回の消費：星くず6 / 三日月14 / 砂糖菓子18 / 彗星24
三日月は3弾まとめて14消費。砂糖菓子は中・大ランクだけを抽選。彗星は貫通弾。
被ダメージ：1ハート。無敵時間：1.5秒。
月のハート：最大ライフ+1、上限4。現在ライフは増えません。
地形：5種の手作り足場をランダムに接続。地面は連続し、落下死はありません。
歩行：移動距離に同期する8コマ。立ち撃ちの脚は固定、移動撃ちでは歩行を継続。
お菓子には光輪・粒子、杖と月のハートには光の柱・矢印があります。
箒の飛行・ホバリング、ゲームパッド、BGM、保存機能は今後の拡張です。

ファイル構成（GitHub用配布版）

style.css：ページ・HUD・タッチ操作の外観
engine.js：ルール、生成、物理、戦闘。CFG / BOSS / WANDS / SWEETSが主な数値設定。

.nojekyll：静的ファイルをそのまま配信するためのマーカー
README.txt：この説明

GitHub用配布版は、この構成のままリポジトリの公開対象フォルダーに置けます。
すべて相対パスで参照し、外部ライブラリ・CDN・ビルド工程は使っていません。
Sites用の管理設定・認証情報・Git履歴・確認用のボス開始コードは含みません。
開発チェックアウトではゲーム本体をdist/に置き、test.cjsはdist/engine.jsを参照します。

検証
ルールテスト41項目に合格。300個の生成ステージ、回復、変身、復活、杖、エネルギー、照準とキー操作を含みます。
ボス本体を左右両側から複数の踏切距離で越えるテスト、地上弾・突進の回避テストに合格。
初期杖・2ハートで照準、後退、ジャンプを行い、ボスをお菓子にして食べるシミュレーションに合格。
実ブラウザーでも斜め射撃、エネルギー消費、Wジャンプ、Spaceによるドア移動を確認。
これは全プレイヤーにとっての難易度を保証するものではなく、操作感とバランスは引き続き調整対象です。
