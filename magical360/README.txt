チャプター2「夜の街」
ステージ1「夜の商店街」：街の入口 → 市場通り → 店舗の裏路地
ステージ2「倉庫街」：搬入口 → 荷物用昇降機 → 仕分け倉庫
ステージ3「街外れの搬出場」：運搬路 → 食料の集積所 → 対決広場
全3ステージ・9エリア。地形・敵・アイテムの配置は固定です。
乗れる荷車、上下する荷物用昇降機、魔法2発で壊れる木箱を配置。
各エリアの出入口でSpaceを押すと次へ移動します。昇降機のエリアでは上階に出口があります。
黒髪・赤目のナニワが初登場。関西弁の会話、登場時の失敗、早合点での対決、戦闘後の和解を実装。
ナニワは3方向の魔法、地上突進、跳躍攻撃を使います。HP半分以下で速度と頻度が上がります。
人間のライバルのため、お菓子には変化しません。撃破後に着地し、会話イベントを経てチャプター2クリアです。

開始・持ち越し
通常はチャプター0 → チャプター1 → チャプター2の順に進みます。
チャプター1の結果画面の「街へ進む」で、所持杖・現在/最大ライフ・幸福度・エネルギー・計測時間を持ち越します。
開始画面には「チャプター2から遊ぶ」を追加。こちらは初期ライフ2、星くずの杖、幸福度0から始まります。
再挑戦は選んだ開始地点から。チェックポイントや途中セーブはありません。
チャプター0のアイテム/成長は本編へ持ち越しません。初回クリア後のスキップ記憶は維持しています。
チャプター3〜12は構想のみで、今回の実装には含みません。

操作
移動：A/D または ←/→。同方向のダブルタップでダッシュ。
ジャンプ：W または ↑。Spaceは出口以外ではジャンプ。
魔法：左クリック（カーソルの方向）。Z/Jも使用可。エネルギーは時間回復。
杖の切り替え：マウスホイール または Q。最大2本。アイテム取得/交換：E。
次のエリア：出口の前でSpace。会話が残っていてもスキップして移動。
イベント文字送り：クリック、Enter、Space。全文表示 → 次の台詞。
イベントのAUTOは全文表示後に読む時間を設けます。スキップも使用可。
ステージ上の通常会話は自動送り。AUTO/SKIPは表示しません。
一時停止：Esc。PCでは効果音を初期ON（音は最初の操作後に有効）。

基本ルール
魔物のHP0でお菓子化し、接触した瞬間に食べ終わり、撃破確定。5秒放置するとHP全快で復活。
幸福度は小1/中5/大12。100%で1ハート回復して0へ。満タン時は99%で止まり、被弾後も次のお菓子まで回復しません。
ハート取得は最大ライフと現在ライフを同数増加（上限4）。既に欠けているライフは埋めません。
イベント中・画面切り替え中・決着後はクリア時間を停止。通常プレイ中の会話では計測を続けます。
チャプター1/2ではライフ0になった瞬間にゲームオーバーを表示します。
