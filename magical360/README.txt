魔法少女ミロードちゃんと真夜中のお菓子 — v0.148

HTML / Canvas の固定ステージ型2Dアクション試作です。
実装済み：チャプター0（チュートリアル）、1（月あかりの森）、2（夜の街）、3（星明かりの穀倉地帯）、4（眠れる学術都市）。
現時点の最終チャプターは4です。チャプター5以降は未実装です。

起動・配置
index.html をブラウザで開いてください。ビルド処理や外部ライブラリは不要です。
GitHub Pages等には、ルートのHTML/CSS/JS、.nojekyll、assetsフォルダを配置します。
画像・BGMはHTMLに埋め込まず、assets内のファイルを相対参照しています。
tests / docs / README.txt / ASSETS.txt は開発・資料用で、ゲーム起動には不要です。
ブラウザの制限により、サウンドは最初のクリック・キー操作後に再生されます。

操作
左右矢印 / A・D：移動。同じ方向を素早く2回入力すると地上ダッシュ。
W / 上矢印：ジャンプ。押す長さによって高さが変わります。
空中で左右2回入力：箒で空中ダッシュ。魔力15消費、弾に対して無敵。
左クリック：カーソル方向へ魔法。ホイール / Q：杖の切替。
E / Space：アイテム取得、ドア、水門、移動書架、読書台の操作。
イベント中のクリック / Space：文字をすべて表示、次の台詞へ。
道中の会話は自動送りです。会話ウィンドウ上でも魔法を撃てます。
Esc：一時停止。一時停止中に所持強化の確認やタイトルへ戻る操作ができます。
スマートフォンでは画面下の仮想パッド・ボタンを使用します。

基本ルール
初期ライフ3、残機2、星くずの杖1本から開始します。杖は所持数無制限。オプションで切替対象を選択。
敵をHP0でお菓子に変え、接触して食べると撃破。通常5秒で全快して復活します。
幸福度100%でハート1回復。ライフ満タン時は99%で止まります。
ハートの器は撤廃。ド根性で最大ライフ+1・全回復。
ライフ0で残機を使う場合はステージ冒頭から、ボス戦ではボスから再開します。
チャプタークリアで残機1回復、次のステージへ自動で進みます。
チャプタークリアでステータス強化・新しい杖・スキルを各1つ取得。全解放済みの枠は省略。Ch0には報酬なし。
Ch0で得た装備、ライフ、幸福度などは本編へ持ち越しません。
タイムはチャプターをまたいで累計。操作できないイベントや演出中は計測を止めます。
クリア記録・設定はブラウザのlocalStorageへ保存されます。

デバッグ
ローカルファイルまたはlocalhostで ?dev=1 を付けて起動すると開発用コマンドを利用できます。
Ctrl+Shift+Dで入力欄を開きます。helpで一覧を表示します。
コマンド：chapter 0〜4 / boss 1 / boss 2 / boss 2 fight / boss 3 / boss 4 / title

構成
content.js：Ch0/1の台詞・構成
chapter2-content.js / chapter3-content.js：確定済みのマップ・台詞・発生条件
engine.js：共通の物理・戦闘・操作状態・会話進行
chapter2.js / chapter3.js：章固有の仕掛け・敵・イベント
continues.js：残機・リトライ
presentation.js：暗転・被弾・死亡などの演出進行
game.js：画面描画、ブラウザ入力、HUD、BGM、メニュー
chapter2-art.js / chapter3-art.js / king-art.js：背景・敵の描画とCanvasフォールバック
sfx.js：効果音
index.html / style.css：画面構成・レイアウト
assets：現在使用するPNGとMP3のみ。一覧はASSETS.txt。
docs/art：画像生成条件・制作時の資料。実行時には読みません。
docs/history：旧仕様・変更履歴。現在の仕様書としては使用しません。
tests：現行仕様の自動テスト。Node.jsで node tests/run.cjs を実行します。
