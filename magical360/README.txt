起動
index.htmlをChrome / Edge等で開いてください。
content.js・engine.js・game.js・style.css・assetsを同じ構成で置きます。
画像はassets/miload-motion-v2.pngの外部PNG。ビルド・CDNは不要です。

今回の構成
ローグライクから固定ステージ制アクションへ変更しました。
地形、敵とアイテムの配置は毎回同じです。敵から戻るお菓子の抽選は継続します。
チャプター0：プロローグと基本操作チュートリアル（1ステージ・2エリア。室内は3部屋。最後の森への出入口はイベント）。
チャプター1：ステージ1「月あかりの森」、2「硝子の庭園」、3「真夜中の古城」。
既存の3エリアをそれぞれ独立したステージに整理し、現時点では各1エリアです。
最後のステージに夜菓子の王さまが登場。食べるとチャプター1クリア。
最終構想は全12チャプター。チャプター→ステージ→エリアの階層をcontent.jsに記載。
チャプター2以降、複数エリアの追加、中ボスの実装は今回の対象外です。
今後、各チャプター末尾にボス、必要な途中ステージに中ボスを配置します。

チャプター0
開始画面の「チャプター0をスキップする」で直接チャプター1へ進めます。
初回クリア後はチェックが自動で入ります。外せば再プレイできます。
クリア記録だけをlocalStorageに保存。装備や進行状況のセーブ機能はありません。
記録は同じブラウザー・同じ公開先に限ります。ローカル版とサイト版の記録は別です。
保存が禁止された環境でもプレイ可能ですが、ページを閉じると記録は残りません。
出口では、杖・アイテム・幸福度・現在/最大ライフ・魔力・戦闘状態を初期化。
チャプター1は星くずの杖1本、ライフ2/2、幸福度0%、魔力100から開始します。
最初のスライムも接触するとダメージを受けます。魔法でHPを0にするとクッキーに戻ります。

プロローグ・メッセージ
CHAPTER 0台本Ver.0.1をcontent.jsに収録。台詞と表情は同ファイルで差し替えられます。
冒頭は約36秒のスプライト演出と台詞で進みます。
クッキーが震えてスライムに変身し、ミロードが驚いて杖を構え、逃げた魔物を追います。
冒頭は「スキップ」またはEscで省略可能。通常再生・省略とも同じ状態で操作が始まります。
会話ウィンドウには専用の外部PNGから描画した6種の表情を表示します。
チャプター0は暗い森に囲まれた家と裏庭。家の室内・家具・外観・庭を専用に描画しています。
章・ステージ開始時とドア移動時に、暗転・タイトル表示・フェードインを追加。
演出中は戦闘・回復・お菓子のタイマーを停止。一時停止やタブ非表示でも演出時間は止まります。
チュートリアルの会話中は、移動・敵・弾・回復・お菓子の期限などゲーム内時間が停止します。
ステージ中の会話は全文表示後に読む時間を置いて自動で進み、AUTO・SKIPボタンは表示しません。
画面内の任意の場所をクリックすると全文表示、もう一度で次の台詞へ。Enterでも送れます。
▼は文字送り中に速く跳ね、全文表示後は穏やかに跳ねます。停止・音量・スキップ等の操作ボタンは通常どおり使えます。
変身・食事の台詞は実際の操作結果に連動し、同じ場面では繰り返しません。
一時停止中は会話タイマーも停止。移動・魔法の操作キーは会話送りに使用しません。

操作
A / D・← / →：横移動。W / ↑：ジャンプ（長押しで高く）。
左クリック長押し：カーソル方向に魔法。ホイール：杖切替。
E：杖・最大ライフ増加アイテムを拾う。杖2本所持時は交換する枠を選択。
Space：ドア前で次へ。表示中・待機中のメッセージはスキップします。それ以外ではジャンプ。
補助操作：Z / Jで魔法、Q・1 / 2で杖切替。Escで一時停止。
タッチボタンにも対応。PCでは効果音が初期ON。右上の♪で切り替えます。

継続するルール
敵を魔法でお菓子に変え、5秒以内に触れると撃破。時間切れは全HPで復活。
魔法はエネルギーを消費し、毎秒18回復。最大100。
杖は最大2本。章1のステージ間は装備・現在/最大ライフ・幸福度・魔力を継続。
幸福度100%で1ハート回復し0%へ。ライフ満タン時は99%で停止。
被弾で幸福度は減らず、99%で被弾しても次に食べるまで回復しません。
月のハートは最大ライフ+1、現在ライフも+1。上限4（最大値に到達済みの場合は追加回復なし）。死亡時は初期状態から再挑戦。
5方向ボス弾、ジャンプで越せる本体と突進、足場上の敵はv0.5を継続。
体と杖は照準で回転せず、弾だけがカーソル方向へ飛びます。

開発・配布
node test.cjsでルールを検証できます。Sites管理情報や認証情報は配布に含みません。
Sites開発チェックアウトでは本体をdist/へ配置し、ルートのtest.cjsで検証します。
HTML・画像・スクリプトはすべて相対パス。GitHub公開フォルダーへそのまま配置できます。
