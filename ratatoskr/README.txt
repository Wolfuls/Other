RatatoskЯ — TLブックマーク（統合試作版 v3）

開き方
  ZIPをすべて展開し、ratatoskr-unified フォルダの index.html を開いてください。
  index.html / shared / episodes は同じ階層に置きます。
  HTMLだけを別の場所へ動かすと、画像・画面・各時期のデータを参照できません。
  今回は既存の第2話フォルダへ上書きせず、別フォルダで試せます。

今回の入口と読み方
  最初は「ブックマーク」の「タイムライン」タブが開きます。
  TLを丸ごとブックマークできるという設定で、両話を保存済みのTLとして並べています。
  ニュースの見出しと、その頃の日常投稿を手掛かりに読む時期を選びます。
  「造花事件・続報」301投稿／「LUNA隊の中層出動」262投稿。
  各TLの画面・返信の展開・スレッド・編集操作は第2話の形式です。
  TLを開くと「未フォローも含む」を選んだ状態になります。
  左メニューまたはTL上部の「ブックマーク」から一覧へ戻れます。
  「投稿」タブでは、現在開いている時期のTLで保存した個別投稿を読めます。
  プロフィールは、その時期の本人の発言一覧に戻しました。別時期への発言リンク・引用ボタンはありません。
  アカウント名を押したときのプロフィール表示も、従来の自己紹介と運用スレッドの表示に戻しています。
  既存の台本に新しい引用発言や接続用の会話は追加していません。

会話の読み方
  投稿の「返信」（吹き出しと返信数）を押すと、一連のやり取りを読む画面が開きます。
  前の発言と、返信・引用で続いたやり取りを古い順に表示します。
  共通の元投稿を引用しただけの別の応酬は、同じ会話へまとめません。
  返信先・引用元は短いリンクとして表示し、押すと画面内の該当発言へ移動します。
  「選んだ投稿へ」で開くきっかけになった発言へ、「最初から読む」で冒頭へ移動します。
  「TLに戻る」で、元の表示・検索条件と読んでいた位置へ戻ります。
  返信の投稿フォームは会話の末尾にある「返信を書く」から開けます。
  TLの投稿順・各アカウントの本文・既存の返信先は変更していません。

素材について
  第2話は軽量化済みのv13を使用しました。
  第1話は以前添付された Ratatoskr-scene (2).html を仮素材として使用しています。
  今回指定されたWindows作業フォルダは、この制作環境から直接参照できませんでした。
  そのフォルダ内の最新版との一致は未確認です。
  本文、発言者、返信・引用のつながり、各回のスレッド設定は元データを維持しています。
  第1話の埋め込み画像をファイルへ分離し、共通のシジマ／ニーベルング画像は第2話の縮小版を使っています。
  第1話の大きな報道画像は原寸PNGを残し、表示にはWebPを使用します。

保存と編集
  編集やブックマークは時期ごとにブラウザ内へ保存されます。
  端末・ブラウザ・ファイルの配置先を変えた場合、保存内容が引き継がれないことがあります。
  「HTMLを保存」「シーンを書き出す」の対象は、その時点で開いているTLです。
  保存HTMLはこのフォルダの index.html と同じ階層へ置いてください。
  保存HTMLからも他の時期へ移れますが、他の時期の編集内容まではHTML内に取り込みません。
  JSONバックアップを読み込む場合は、先に対象の時期のTLを開いてください。
  制作済みの全時期を持ち運ぶ場合は、このフォルダ全体をコピーしてください。

シリーズを増やす／本文をファイルで編集する場合
  読むだけならPythonなどの追加インストールは不要です。
  ファイルで編集する場合は episodes/<時期のキー>/scene.json を原稿とします。
  ブラウザから書き出したJSONを使う場合も、対象のscene.jsonへ保存します。
  画像パスは常に共通画面の index.html のある階層からの相対パスです。
  新しい時期は shared/archive-index.json の records に追加します。
    key: 半角英小文字・数字・ハイフン・アンダースコアの識別子
    title / titleJa: 見出し
    news.id: 入口に使う報道の投稿ID
    daily: 入口に使う日常投稿のidを持つオブジェクトの配列
  recordsの先頭が最新の時期になります。
  ファイル編集後、Python 3.9以降で次を実行してください。
    python tools/rebuild-data.py
  scene.js、一覧のJS、index.html内の初期データなどを更新します。
  ブラウザに以前の編集が残っている場合は、対象のTLで「初期シーンに戻す」を使うか、新しいブラウザプロファイルで確認してください。
  既存の投稿IDは、別時期なら重複していても構いません。同じ時期の中では一意にします。
  時期をまたぐ引用は quoteEpisode に引用元の時期のキー、quoteId に投稿IDを指定します。
  一覧の抜粋は既存投稿から作成し、投稿本文そのものは変更しません。

検証
  Chromium・ローカルHTTPで、両話の表示、返信、ブックマークからの移動、プロフィール表示、保存と再読込、
  390px幅の表示、画像読込、JSエラーなしを確認しています。
  画面外の描画延期と、操作時にスクロール位置を維持する更新方法は第2話から継続しています。
  初回から第1話全体を描画せず、選んだ時点でデータを読み込みます。
  ファイルを直接開けるよう相対パスと通常のscript読込で構成し、fetchや外部CDNは使っていません。
  ただしこの環境はfile://によるブラウザ表示が禁止されているため、Windowsでの直接起動確認は未実施です。
  verification/conversation-v3.json が今回の変更の確認結果です。
  bookmarks-v2.json はブックマーク改修時、その他は統合v1時点の確認結果です。
