# RatatoskЯ — ローカルTLシミュレーター

`Ratatoskr.html` をブラウザーで開けば使える。インストール・ログイン・インターネット接続は不要。ロゴ・見た目・動作はHTMLファイル内に収めてある。

## 自分のキャラクターのTLを作る

1. 画面下の **Edit scene → Your character** で名前、ハンドル、アイコン、自己紹介を変更する。
2. **Create a thread** で話題別のスレッドや、自分用の日記スレッドを作る。
3. **Add post** で投稿を追加する。投稿ごとに別の人物の名前・アイコンを指定できる。
4. 投稿右上の **···** で本文、時刻、返信先、添付画像、反応数を編集する。**↑ / ↓** で全投稿内の並び順を変えられる。文章も変更した場合は **Save changes** で確定する。
5. スレッドの **Follow / Following** でフォローを切り替える。**Home → Following** にはフォローしたスレッドの投稿だけが表示される。**All threads** では全スレッドの投稿を表示する。

初期投稿を消す場合は **Edit scene → Clear all posts…**。直前の変更は **Undo last edit** で戻せる。

## スクリーンショットを作る

- 下部の **Screenshot** を押すと、編集ツールと各投稿の編集ボタンが消える。これは撮影用の表示切り替えで、画像ファイルを自動生成するボタンではない。
- Windows の **Win + Shift + S** などで画面を撮影する。
- **Esc** または **F8** で編集モードに戻る。ロゴのダブルクリックでも戻れる。F8は撮影モードへの切り替えにも使える。
- **Edit scene → Timeline-only layout** で中央のTLだけを表示できる。
- 右上の月アイコンでライト／ダークを切り替えられる。
- 画面幅はブラウザーのウィンドウサイズやズームで調整できる。

## 保存・持ち運び

- **Save HTML**：現在の投稿・画像・キャラクター・スレッド・テーマ・表示ページを含むHTMLをダウンロードする。このファイルだけで別の場所でも再開できる。スマートフォン幅では下向き矢印のアイコンで表示される。
- **Edit scene → Export scene**：シーンをJSONで保存する。
- **Edit scene → Import scene**：保存したJSONを読み込む。現在のシーンを置き換えるため、残したい場合は先に書き出す。
- 通常の編集はブラウザー内にも自動保存する。ただし、ローカルファイルの自動保存はブラウザー設定・ファイルの移動・プライベートモード等の影響を受ける。残したいシーンは **Save HTML** または **Export scene** で書き出す。
- 元のHTMLファイルが自動で上書きされるわけではない。ダウンロードした新しいHTMLを保存する。
- アバター・添付画像はPNG／JPEG／WebP／GIF、1枚6MB以下。画像が多いとブラウザーの保存容量を超えることがある。その場合もHTMLに書き出して保存できる。

## 再現範囲・設定の扱い

英語UI、アカウント、スレッド単位のフォロー、個人用スレッド、実況スレッド、投稿、返信表示、いいね、再投稿の反応、ブックマーク、検索を備えた撮影用の模擬画面だ。通信や他者への投稿は行わない。反応数・フォロワー数・時刻は演出用の表示値で、再投稿は反応ボタンとして扱う。時刻に応じて自動ソートせず、投稿順は手動で管理する。

ラタトスクの仕様は今回提示された設定に従った。初期キャラクター（Alex Morgan、Mira等）、投稿、スレッド、出来事、英語のサービス文言は、この再現用に作成した創作サンプルであり、公式設定の追加や確定情報ではない。ロゴは提供された画像を使用している。

同梱の `Ratatoskr-preview.jpg` は初期画面の撮影例。

検証：ローカルプレビューで投稿編集、スレッドのフォロー絞り込み、撮影モードの切替、スマートフォン幅の表示を確認。HTMLダウンロード後の埋め込みデータとスクリプト構文を確認した。検証用ブラウザーでは file: URL の表示が許可されないため、ダブルクリックで開いた場合の実機検証は行っていない。
