# RatatoskЯ アイコン集 01 — イラスト版

4×4シート2枚から切り出した、32種類の正方形PNG。画像生成は内蔵ツールで2枚のシートとして実行し、写真調だった17種類を同ツールで二次元のイラストに変換した。人物5人はアニメキャラクター風、動物・風景・小物は挿絵風に統一している。

- `index.html`：ダブルクリックで開ける一覧。Circle / Squareで表示形状を切り替え、各Download PNGから保存できる。
- `icons/`：個別PNG32枚（304×304px）。01〜24は返信・引用アカウントに割り当て済み。25〜32は予備。
- `sheet-A.png` / `sheet-B.png`：イラスト調へ変換したシート。各1254×1254px。既にイラストだった15枚の個別PNGは前版を保持している。
- `manifest.json`：ファイル名・アカウントID・切り出し位置の対応表。
- `generation-prompts.txt`：初回生成と今回のイラスト変換に使用したプロンプト全文。

画像の被写体はSNS利用者が選んだアバターとしての創作。人物は架空の成人であり、人物画像の外見からキャラクターの設定を確定する意図はない。

## RatatoskЯでの利用

`Ratatoskr-Enmi.html`の該当24アカウントには画像を反映済み。HTMLには軽量化した256×256pxのWebPを埋め込んであり、HTMLファイルだけでオフライン利用できる。静寂・NIBELUNG REPORT・Bifrost Buzzの既存アイコンは維持した。

予備アイコンは、投稿右上の「···」からAvatar imageを選んで設定できる。編集後はSave HTMLで保存する。別の投稿にも同じアカウントを使う場合は、同じ画像を設定する。

ZIPを展開する場合、一覧のHTMLとiconsフォルダーの位置関係を保つこと。PNGそのものは単独でも利用できる。
