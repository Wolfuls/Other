Ygg Round v1.10 — Windows アプリ版（64bit）

起動
YggRound.exe をダブルクリックしてください。インストール作業は不要です。
アプリ内でキャラシート .xlsx を読み込み、そのまま使用できます。
ネット接続なしでキャラシート読込・計算・履歴・保存が動きます。

これまでのサイト版・HTML版から引き継ぐ
1. これまで使っていた版で「バックアップ」から JSON を保存します。
2. アプリ版の「復元」で、その JSON を選びます。
サイト版・HTML版・アプリ版はそれぞれ別の保存場所です。自動では同期しません。
復元は保存済みキャラを別キャラとして追加する処理です（画面の案内を確認してください）。

しおり専用表示と独立ウィンドウ
起動すると画面右端にしおりが表示されます。通常表示への切替はありません。
HP／PP／暴走率／因子（Rd）／総消費PP／SPE／カルマはしおりに常時表示します。

・今回の宣言／行動履歴／キャラ設定：しおりの左へ引き出します。
・行動一覧／期待値／盤面の補正：それぞれ別ウィンドウで開きます。
  3つを同時に表示でき、タイトルバーで移動、枠の端でサイズ変更できます。
・補正の保存や宣言の変更は他のウィンドウへ自動反映します。
・各ウィンドウの「×」または同じしおりを押すと、そのウィンドウを畳みます。
  再度しおりを押すと同じ内容を表示します。
・「すべて畳む」は全ウィンドウを畳み、「終了」はアプリ全体を終了します。
・最前面表示が標準です。「⋮⋮ 移動」を右クリックすると一括解除できます。
・しおりは「⋮⋮ 移動」をドラッグして移動できます。
・今回の宣言の「管理」からバックアップ、復元、手動作成、使い方を開けます。
・補正などの編集フォームを開いている間は、他の画面の操作を一時停止します。
  フォームを保存・キャンセルするか、そのウィンドウを畳むと操作できます。
・アプリの終了やキャラ切替で未登録の宣言は破棄されます。
  必要な宣言は「この宣言を登録」で履歴へ残してください。
・旧版を閉じてから新しいexeを起動してください。保存済みキャラ・履歴は引き継ぎます。
・ユドナリウムとは独立したアプリです。ユドナリウムとは自動同期しません。

前回の更新（v1.8）
・今回の宣言をしおりの主画面にし、行動一覧を独立ウィンドウへ移しました。
・行動一覧／期待値／盤面の補正には状態バーを表示しません。
・因子の単位をRdに統一し、基本行動を応用技より前に配置しました。
・IN／AC／RE／ENは確認後に切り替え、未登録の宣言とメモを空にします。
・特殊武装、SPE、カルマ、消費アイテムをシートから取り込みます。
  既存キャラには「所持品をExcelから追加」で追加できます。
  登録済みの同じ所持品・残数・使用回数は上書きしません。
  「＋ 所持品」または編集から、名称・効果・残数等を設定できます。
  消費アイテムの購入価格は使用時に差し引きません。
  マグタフ／EX／Zを自分に使う場合は、実際の出目による回復を反映します。
  特殊な効果・反動・他者への効果は、ルールを確認して状態や補正へ記録してください。
  不明な名称はそのまま表示し、効果・コストを確認してから宣言できます。
・「コンディション」でHP・PP各2D6、武装の圧迫SP×3、PP分の暴走を反映します。
  進行表に含まれている上昇分は読込済みとして扱い、再入力は差分だけ反映します。
  振り直しは1 Rdを消費。入力ミスの訂正も選べます。履歴から巻き戻せます。
  所持しているマキシマムは、この欄で使用できます。

保存先と更新
キャラクターデータは %LOCALAPPDATA%\YggRound\UserData に自動保存します。
表示用ファイルは %LOCALAPPDATA%\YggRound\Application に展開します。
exeの置き場所やファイル名を変えても、保存先は共通です。
次回更新時はアプリを閉じ、新しいexeに置き換えてください。
大切なセッションは定期的に「バックアップ」でJSONも保存してください。

動作環境
Windows 10/11（x64）、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
このPCにインストール済みのWebView2を使用します。
別のPCで「WebView2 Runtimeが必要」と表示された場合は、Microsoft公式から
Evergreen Runtimeをインストールしてください。
https://developer.microsoft.com/microsoft-edge/webview2/

前回の更新（v1.9）
・ダメージ表示を「当たった時はn点入りそう」に変更。命中した場合の平均値です。
  装甲・増強軽減・倍差命中・スマッシュを含み、空振りは平均に含めません。
・トレイにSPE・カルマの名称と@残り回数を表示。常時効果は「常時」、無制限は@∞。
・HP・PP・暴走率・因子・総消費・SPE・カルマをクリックすると文字列をコピーできます。
  例：HP 30/49、SPE リテイク@2。クリップボードが使えないブラウザでは選択欄を表示します。
・アタッチメント横のE列は固有名として取り込み、消費アイテムと重複させません。
  既存キャラの誤読も、元のセル位置から対応を確認できる場合に修正します。
・SPE・カルマ・消費アイテムは原則コストなし、残り回数を中心に表示します。
  例外：共鳴・奥義PP4、使役者PP5、精神凌駕の残PP、愛のHP/PP、帝王②のHP。
  反動やその他の固有効果は引き続き手動処理です。
・消費アイテムは1個につき1回。購入価格は使用時に差し引きません。
・複数効果のSPE・カルマは効果ごとに使用回数を管理します。
  英雄・凡骨の同ラウンド1回制限も管理します。エキスパートの判定単位の制限は手動確認です。
・登録済みのルール由来データを更新し、使用済み回数や個数、手動で編集した内容は保持します。
・Windowsの引き出しと独立ウィンドウを小さくし、余白・入力欄を整理しました。
  長い効果と分布グラフは開閉でき、Windowsの状態欄は右端にまとめています。


今回の更新（v1.10）
・探索中の基本行動に12種類の探索技能と能力精度を追加しました。
・行動は検索欄で候補を絞り、プルダウンで選択します。選択後に構成と効果を確認できます。
・「寵愛【アイドル】」など補足名付きのカルマと、価格付きの消費アイテムを読み取ります。
・餓狼・風雲児・無頼漢はセッション2回、1ラウンド1回として管理します。
・シートの消費アイテム名を照合し、各1個1回で残数を管理します。
  旧シートのパイル・荷電粒子予備弾は、現行RWに効果の記載がないため卓のルールで扱ってください。
・HP、PP、暴走率、因子、総消費、SPE、カルマを「全状態をコピー」で1行にまとめます。
・対抗判定の指定欄を大きく上部に配置。「期待ダメージ」は命中した時の平均です。
・既存キャラの既知のルール項目を更新し、手動編集・使用履歴・アイテム残数は保持します。
