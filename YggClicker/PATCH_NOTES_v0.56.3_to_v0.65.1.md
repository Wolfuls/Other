# YggClicker v0.56.3からv0.65.1のパッチノート

PROTOTYPE v0.56.3以降に追加・変更された機能を、v0.65.1の最終仕様でまとめています。グラフィック変更と、途中で撤回された仕様は含みません。

## 育成とステータス

- 能力ごとの個別レベルを、キャラクター共通のレベルに統合しました。雇用時はLv.1。各強度と行動力は、雇用時を基準に1Lvにつき線形で2%成長します。成長倍率は `1 + 0.02 × (Lv − 1)` です。
- 育成価格は従来の攻撃力強化の初価を使用し、購入ごとに1.125倍になります。1Lv・10Lv単位の購入と売却ができます。固定のレベル上限と、毎Lvの能力値＋1保証はありません。
- 基礎能力と育成による強度を分離しました。命中・回避・攻撃・HP・防御に強度があり、SSは独立した基礎能力として表示します。SSによる攻撃は命中強度、SSによる回避は回避強度を使います。防御と抵抗は防御強度を共有します。
- **強度欄は「キャラクターLv × その能力のCP倍率」**を整数で表示します。CP未配分ならLvと同じ値です。敵は挑戦Lvに対応する値を表示します。これは表示尺度の変更で、戦闘計算の倍率を変更するものではありません。
- 行動力欄と最大HP・HPゲージは、実際に戦闘で使う値を表示します。HP強度と防御強度は独立しており、HPへ特化すれば同じ防御性能でも耐えられる攻撃回数が増えます。
- 最大HPは「基礎HP × 育成倍率 × HPへのCP倍率」の切り捨てで算出します。最大HPの増加では現在HPを回復せず、減少した場合は新しい最大HPまで切り詰めます。

## 個人コンセントレイション

コンセントレイションはキャラクターごとに設定します。雇用時のCPは0、レベルアップごとに1CPを獲得し、行動・命中・回避・攻撃・HP・防御へ配分できます。

獲得CP総数をC、その能力への配分をPとして、補正は次の式です。

```text
有効CP = P / (1 + 2.5 × P / C)
CP倍率 = 1.08 ^ 有効CP
```

Cが0なら倍率は1です。同じ能力への配分を増やすほど、追加1CPあたりの伸びが緩やかになります。

未使用CPの配分は無料です。確定済みの配分は、能力画面の「振り直す」から戻せます。費用は現在Lvまでの育成投資額の5%で、切り捨て・最低1Rd。確定前の追加配分は無料で戻せます。

## 戦闘計算

- 命中判定には命中強度と回避強度の比、ダメージ判定には攻撃強度と防御強度の比を反映します。基礎ロールの相性を残しながら、実ロールへ加える整数補正として計算します。味方・敵・見込み表示は同じ計算を使います。
- ダメージには両者の強度に応じた戦闘規模も反映します。同格同士ではHPとダメージが同程度に伸び、高Lvになっただけで戦闘が極端に長期化することを抑えます。大きな強度差がある場合も、最終ダメージの最低値は1です。
- 防御貫通は防御力と防御強度の両方を無視します。対象に「貫通無効」がある場合は、どちらも無視できません。
- 全体攻撃は防御計算後のダメージを半減します。倍差命中では追加1D6の代わりにこの半減を解除します。スマッシュクリティカルの追加ダイスは適用します。
- プレイヤー自身の手動攻撃「あなた」は必中・1ダメージ固定です。キャラクターを選んだ手動攻撃は、そのキャラクターの能力を使います。
- APへの攻撃はHPダメージと区別して処理・表示します。APは0未満にならず、APを削るだけでは撃破やHPダメージによる報酬は発生しません。

## 敵の成長と報酬

挑戦LvをQ、`x = Q − 1` として、敵の内部強度・最大HP・行動力には次の成長倍率を使います。基礎ダイス式や防御・抵抗の固定値とは分けて扱います。

```text
敵の成長倍率 = 1.012^x × (1 + x/100)^[100 × ln(1.025/1.012)]
```

初期の伸びから、高Lv帯では緩やかな伸びへ移ります。能力画面の強度欄は、この倍率そのものではなく挑戦Lvに対応する数値です。

初期報酬をR0としたクリア報酬の成長式は次のとおりです。

```text
報酬 = R0 × 1.14^x × (1 + x/100)^[100 × ln(1.25/1.14)]
```

- クエスト強化費は100Rdから始まり、購入ごとに1.15倍になります。
- 全体強化「クエスト報酬強化」の1Lvあたりの加算額は、挑戦Lvに応じた報酬の10%を切り捨てた値で、最低1Rdです。
- ジュエルの臨時収入など、クリア報酬以外の獲得因子も収入源ごとに記録します。売却や移行時の返還は、総獲得因子には加えません。

## 暴走率と活性

各キャラクターに暴走率・活性タイプ・基礎暴走圧を追加しました。編成中かつ戦闘可能なキャラクターは、基礎・育成・有効パーク・一時効果から暴走圧が発生します。鎮静圧は暴走率を下げる方向へ働きます。

| キャラクター | 活性タイプ | 基礎暴走圧 |
| --- | --- | ---: |
| メタ・ゲルハムト・ジュエル | 覚醒型 | 1.2%/分 |
| ビシュナル・元加 枠 | 反応型 | 0.6%/分 |
| トルデリーゼ・マックス | 回復型 | 0.3%/分 |
| ミツル | 回復型 | 1.2%/分 |
| クイーン | 反応型 | 1.8%/分 |

育成由来の暴走圧は `0.6 × log2(キャラクターLv)` %/分です。未編成・戦闘不能・暴走離脱中は正の暴走圧が止まり、鎮静のみを適用します。

- 暴走率50・60・70%で活性が1段階ずつ、最大3段階になります。反応型は命中・回避・SSの固定値が1段階につき＋1。回復型は自然回復速度＋20%、正の暴走圧−10%が1段階ごとに加算されます。覚醒型の固有効果は現在未設定です。
- 80・90%では、攻撃・命中・回避・SS・行動力の能力ロールに1D6ずつ、合計最大2D6を追加します。
- 50・70・90%を上向きに通過すると暴走ロールを行い、自傷・暴発・暴走率上昇・暴走症状などを解決します。症状には行動の失敗、パークの不発、判定・ダメージの低下などがあります。
- 110・120・130・140%では臨界イベントが発生し、自傷またはHP回復・臨界余力を得ます。臨界余力は、以後の暴走率上昇を先に肩代わりします。現時点で臨界因子の獲得量は0です。
- 150%で部隊から強制離脱します。キャラクターは失われず、100%未満に下がると再編成できます。症状は70%未満で解除されます。各閾値のイベントは、その閾値より10ポイント下がると再び発生可能になります。

### 暴走を抑える操作

- 仲間一覧の「暴走抑制」で、対象の暴走率を即時10ポイント下げます。費用は現在の育成投資額の1%。正の金額は切り捨て・最低1Rd、未育成なら無料です。
- 「全体抑制」は表示中の部隊の対象者へまとめて適用し、個別費用を合算します。
- 全体強化「因子安定化」は、全味方の鎮静圧を1Lvにつき毎分＋0.1します。初価20,000Rd、以降は購入ごとに1.5倍です。
- 能力・パーク画面から、基礎・育成・各パーク・活性・因子安定化・部隊支援などの暴走圧／鎮静圧の内訳と計算式を確認できます。

能力・パーク画面では育成・CP・パークの変更をまとめて「確定」できます。×またはEscで未確定の変更を取り消します。パークをOFFにしても、既に付与された状態や予約済みの効果を遡って消すことはありません。

## 追憶と周回

- 所持因子が**1,000,000Rdを超える**と、クエスト「追憶」が解放されます。一度解放すれば因子を使っても表示を維持します。
- 追憶には敵がおらず、キャラクターの配置やクエスト強化はありません。他のクエストの部隊は周回を継続します。
- モノリスにカーソルを合わせると、**今回の周回の総獲得因子**と**全周回累計の総獲得因子**を確認できます。既に消費した因子も獲得実績に含みます。

## 敵の成長と報酬

挑戦LvをQ、`x=Q−1`、`U=1+x/100` とし、基準となる敵強度を次の式で計算します。

`S = 100×1.012^x×U^[100 ln(1.025/1.012)]`

| 項目 | 現在の内部計算 |
| --- | --- |
| HP強度 | S×U^3.5 |
| 防御・抵抗強度 | S×U |
| 攻撃強度 | S÷U² |
| 命中・回避・SSの強度 | S |
| 行動力の育成倍率 | S÷100 |

実HPは「基礎HP×HP強度÷100」の切り捨てです。敵のHP・防御・攻撃の曲線を分離し、部隊全体で複数回攻撃する耐久へ調整しました。基礎能力と味方の育成・CPは維持しています。敵能力画面にも各強度を分けて表示します。

通常報酬は初期報酬R0に対して、`R0×1.04^x×U^[100 ln(1.28/1.04)]` へ変更しました。報酬強化などの補正は維持します。挑戦Lv購入費は、従来の `100×1.15^x` と、100を初価とした現行報酬曲線の小さい方を使用します。

育成価格の×1.125は維持し、長期戦化と進行に応じた育成ペースを調整しています。編成・CP・周回先で所要時間は変わり、固定の待ち時間や10分の上限を設けるものではありません。
