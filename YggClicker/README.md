# YggClicker

『鋼鉄のユグドラシル RW - Red Within -』の非公式二次創作・放置ゲーム試作。
チーム世紀末覇者を全員で自動周回し、クリア報酬の因子でキャラクターを雇用・強化します。

## ローカルで遊ぶ

`index.html` をブラウザで開くだけで動作します。外部ライブラリ、CDN、ビルド、ネット接続は不要です。
HTMLを直接開いた場合のブラウザ内保存はブラウザ依存のため、継続開発では次のローカルサーバーを推奨します。

Node.js 20以上がある場合、このフォルダで以下を実行します（依存関係のインストール不要）。

```sh
node tools/serve.cjs
```

表示される `http://127.0.0.1:4173/` を開きます。終了は `Ctrl+C`。
ポート変更は `node tools/serve.cjs 4174`。サーバーは127.0.0.1のみに接続し、外部公開しません。
`localhost` と `127.0.0.1`、異なるポートは別の保存先になるので、普段は同じURLを使用してください。

## 試作の仕様

- 初期因子5Rd。キャラクター未選択・未強化の手動攻撃は `1D6 + 0`（1～6点）。因子の単位はRd。
- 雇用済みキャラクター全員が、行動点を溜めて自動攻撃。出撃枠なし。
- 規定ダメージに到達すると因子を獲得し、同じ対象のHPを全回復して次の周回へ。
- セッションはチーム世紀末覇者のみ。旧セーブの起動訓練・通路の巡回・重装甲試験は、育成状況を保ってHP10のチーム世紀末覇者へ移行。
- 超過ダメージは原則破棄。攻撃力Lv.50以上でBoM-BeRを購入したリヒター、Lv.30以上で「うな重の差し入れ」を購入したビシュナルは余剰分が後続へ連鎖。敵からの反撃・キャラロストなし。
- 初回購入で雇用、以降は「攻撃威力」と「行動力」を別々に購入。威力はLv.200まで、行動力の強化にはゲーム上の最大Lvを設けません。
- 全攻撃の固定値／行動力／報酬の強化と、30秒間の限界突破を実装。
- 離席中は最大8時間。通常の少数攻撃はダイス判定、大量の攻撃は期待値でまとめて計算。一時停止中は進行しない。
- 自動保存は10秒ごと、購入・一時停止・非表示時。ページ終了時だけの保存には依存しない。
- 同じ保存先での複数タブはWeb Locksで二重進行を防止。非対応環境は保存変更を検知した側を停止。

| キャラクター | 初回雇用費 | 威力Lv.1の攻撃 | 基本行動力 |
| --- | ---: | --- | ---: |
| 鋼音メタ | 10Rd | 2D6 + 0 | 約55.56 |
| ゲルハムト・リヒター | 100Rd | 5D6 + 0 | 25（仮） |
| 右藤ビシュナル | 1000Rd | 10D6 + 0 | 25（仮） |

キャラのLv成長はダメージ倍率：`1 + (攻撃力Lv − 1) × 0.1`。Lv1で等倍、Lv10で×1.9、Lv50で×5.9。複利ではなく加算成長です。パークやコンセントレイションによる攻撃力の固定値は、ダイスの出目にそのまま加算します。
パーク未購入時、メタは各Lvで2D6＋0のまま、攻撃力Lvの倍率が増えます（Lv3は×1.2、Lv10は×1.9）。
全キャラクターは上記のLv倍率に加えて、購入済みパークの効果が累積します。
コンセントレイションは初回5Rdで、全キャラの自動・手動・追加攻撃と未選択時の手動攻撃に固定値＋1／Lv。スピードアップは初回30Rdで、個別強化後の行動力に＋1%／Lv。両方とも累積効果は加算式です。
表示、実際のダイス判定、DPS、離席計算は共通の攻撃式を参照します。

攻撃力の内訳は次の加算式です。

`（基礎攻撃力 ＋ パーク補正 ＋ アップグレード補正 ＋ SPE補正 ＋ アイテム補正）× 攻撃力Lv倍率`

- 基礎攻撃力：メタ2D6＋0／リヒター5D6＋0／ビシュナル10D6＋0。メタルマン購入後はメタの基礎を4D6＋5に置き換えます。
- パーク補正：追加ダイス・固定値・対象に有効な特効。未購入・条件不成立の効果は含めません。
- アップグレード補正＝コンセントレイションの購入Lvぶんの固定値。自動攻撃と手動攻撃に共通です。
- 小計B＝基礎＋パーク＋アップグレード補正。SPE補正＝小計B×100%（限界突破有効時）。無効なら0。
- アイテム補正：現在は0。アイテム購入機能は未実装です。
- すべてを加算して最後に攻撃力Lv倍率を掛け、端数切り捨て後に防御を減算（最低0）。防御無視はこの減算を省略します。

基礎＋パーク＋コンセントレイションの小計を、限界突破中は2倍にします。途中の補正では丸めず、同じダイスの出目を使用します。キャラカードは自動攻撃の現在式を表示し、手動攻撃の下の「計算式・補正内訳」は選択キャラの内訳です。

クリア報酬増加は初回100Rdで基礎クリア報酬＋10%／Lv。`基礎報酬 × (1 + 強化Lv × 0.1)` で、複利ではありません。Lv1の通常報酬は2.2Rd。小数を切り捨てずに獲得・保存します。カードには累積報酬ボーナスを表示。
限界突破は30秒間、全ダメージ×2。価格は「限界突破を除いた、選択中セッションに対するパーティDPS × 100%」を整数に切り上げたRdです。たとえばDPS3.89なら4Rd、DPS1,520.41なら1,521Rd。通常DPSには購入済みパーク・威力Lv・行動力・コンセントレイション・スピードアップ・敵の防御を含め、手動攻撃は含めません。使用中も通常DPSから計算するため価格は2倍になりません。DPS0では使用不可、効果中の重ね掛けも不可。残り時間と既存セーブの状態を維持します。共通の調整値は `js/data.js` の `balance` に集約しています。

### 強化価格（v0.31）

キャラクター固有の攻撃威力・行動力は「初回価格 × 1.15の購入回数乗」、アップグレード欄の繰り返し強化（コンセントレイション・スピードアップ・クリア報酬増加）は「初回価格 × 1.25の購入回数乗」です。初回価格と現在の購入回数から計算し、最後に一度だけ端数を切り上げます。威力・行動力・各アップグレードの購入回数は独立します。

| 購入対象 | 次の購入価格 | 初回価格 |
| --- | --- | --- |
| 攻撃威力（雇用後） | ceil(初回価格 × 1.15^(現在の攻撃力Lv − 1)) | メタ5Rd／リヒター12Rd／ビシュナル120Rd |
| 行動力 | ceil(初回価格 × 1.15^現在の行動力強化Lv) | メタ6Rd／リヒター15Rd／ビシュナル150Rd |
| コンセントレイション | ceil(5 × 1.25^現在Lv) | 5Rd |
| スピードアップ | ceil(30 × 1.25^現在Lv) | 30Rd |
| クリア報酬増加 | ceil(100 × 1.25^現在Lv) | 100Rd |

初回雇用はメタ10Rd／リヒター100Rd／ビシュナル1000Rd。初期因子5Rdから、チーム世紀末覇者を手動で3クリアすると11Rdとなりメタを雇えます。スピードアップの初回価格は30Rd、クリア報酬増加は100Rdです。個別パークと、一度だけ解放するオーバーキルボーナスは固定価格を維持します。

威力Lv50→51はメタ4,712Rd／リヒター11,308Rd。雇用からLv50・全パークまでの総額は32,620Rd／78,266Rd（行動力・全体強化を除く）。威力Lv100→101は5,105,711Rd／12,253,706Rdです。威力はLv200まで。繰り返し型の全体強化と行動力にはゲーム上のLv上限を設けません。オーバーキルボーナスは従来どおり一度だけ購入します。

v0.23の初回価格で試算した「リヒターLv50＋BoM-BeRまで約16分」は旧バランスの参考値です。その後の更新で雇用費・全体強化の基礎価格・全体強化の上昇倍率を上げているため、現在の到達時間の見積もりとしては使用しません。

セーブ形式11と既存の所持因子・Lv・購入済みパーク・行動点・限界突破の残り時間を保持します。形式10以前から段階移行し、新キャラクターは未雇用として追加。削除したセッションでは敵HPだけ10へリセットします。購入差額の返金や振り直しはせず、次回価格を新式で計算します。非常に大きな旧行動力Lvでも攻撃性能は引き継ぎます。指数価格がJavaScript Numberの範囲を超える場合は「計算範囲外」と表示して追加購入を止めます。現在の通貨保存上限1e100も従来どおりです。

### オーバーキルボーナス

アップグレード欄から200Rdで一度だけ購入して解放します。購入レベルは0／1、追加報酬は強化後の通常報酬の25%で固定です。

- 防御を引いたダメージが、その時点の敵HPを20以上超えたら成立（ダメージ適用後HPが−20以下）。HP10なら30ダメージ、残りHP3なら23ダメージが必要です。
- 成立した敵1体につき、割合強化後の通常報酬に＋25%（×1.25）。たとえば報酬強化Lv1なら通常2.2Rd／成立時2.75Rdです。
- 気絶には適用しません。BoM-BeRは各巻き込み先でも防御を引いて条件を判定し、条件を満たした敵ごとに加算します。
- 通常のダイス処理は実際の成立数で計算。大量攻撃・離席中はダイス分布から成立数を近似し、バッチ単位で整数へ丸めます。「因子獲得見込み」には丸め前の長期平均を含めます。

### チーム世紀末覇者

鉄パイプ持ち（赤モヒカン）・ボウガン持ち（青モヒカン）・ケンカ屋（緑モヒカン）・ハンマー持ちのハゲ・ナックル持ちのハゲ・チェーン持ち（黄モヒカン）・女性の警棒／レンチ／バット持ち・鉄斧持ち（橙モヒカン）の10種類。全員HP10・防御0・報酬2Rd。ハゲもグループ共通の[モヒカン]属性として、メタの購入済み特効が有効です。

画面には攻撃対象1体＋後続2体を表示。攻撃・HP・報酬の対象は先頭1体で、撃破・気絶ごとに次が前へ移動します。倒れた個体は独立した画像を持ってダウンし、新しい後続が補充されます。BoM-BeRはこれまでどおり後続へ余剰ダメージを連鎖させます。

各個体は4コマの待機アニメーションを1秒でループ。膝・腕・武器の動きを描き、3体の再生タイミングをずらしています。待機のコマ切り替えと、ヒット・前進・ダウンの位置移動は別レイヤーです。1体ごとのJSタイマーは追加せず、CSSで再生します。一時停止・非表示・動きを減らす設定では停止。高頻度の撃破では前進を毎回巻き戻さず、3枠の外見だけを繰り上げるため攻撃位置から離れ続けません。

表示する3体を含めた戦闘全体が表示幅・高さに収まらなくなった時だけ、自動ズームアウトします。新しく出現する外見は同時表示中の個体と重複しないランダム選択。リロード時も3体を新たに選びます。

10種類すべてに、のけぞり→吹き飛び→転倒→倒れ伏す専用4コマを実装。撃破・気絶のどちらでも発生します。待機と同じ体格に揃え、倒れた身体が収まる横幅で描画します。表示は約0.66〜0.86秒で、最後の姿を少し残してフェードアウト。ランダムな落下方向・移動量は保持し、連続撃破でも個体ごとに再生。実際の撃破・報酬・周回計算は演出を待ちません。

素材は外部透過PNG。待機は img/enemy-*-idle-v1.png（768×224、1コマ192×224）、やられは img/enemy-*-defeat-v1.png（1024×224、1コマ256×224）。通常3体のCSSアニメーションと上限付きのダウン表示だけを使用し、全種類を常時DOMに置きません。旧1枚絵は `img/old/` に保管しています。

### ウトガルドの背景と因子のサイコロ

チーム世紀末覇者のみ、外部PNG `img/utgard-industrial-v1.png` を戦闘欄の背景に設定。原作の工場ビル群・天井に届く建造物・入り組む工業地帯をもとに、配管・高架通路・天井構造を描いています。SESSION見出しの下にあった個体名は、このセッションでは非表示です。攻撃対象・後続の読み上げラベルは保持します。

サイコロ型の因子を戦闘欄の奥に降らせます。秒間の因子獲得見込みが0なら0個、正なら `min(24, 3 + floor(3 × log10(1 + 秒間因子)))` 個を表示。稼ぎに対して対数的に増加し、最大24個。DOMは固定プールで、CSSの移動・透明度だけをアニメーションします。戦闘のズーム倍率には連動せず、キャラクター・操作要素の奥に表示し、クリックを妨げません。一時停止・タブ非表示・別タブによる待機中は停止し、動きを減らす設定では非表示。ゲームの報酬やセーブ形式には影響しません。

### 因子の表示と獲得見込み

所持因子と累計クリア回数は指数表記を使わず、桁区切りで全桁表示します。累計クリアは整数で表示し、読み込み確認や離席中の周回数も同じ形式です。所持因子の小数は第2位まで表示し、不要な末尾の0は付けません。大きな数は折り返します。数値の保存・計算精度は従来のJavaScript Numberのままです。

「因子獲得見込み」は、現在の性能で自動周回し続けた場合の長期平均です。コンセントレイションとスピードアップも反映し、手動攻撃は含めません。

- 平均クリア回数 / 秒 × 通常報酬 ＋ オーバーキル成立回数 / 秒 × 通常報酬 × 25%。クリア報酬増加とオーバーキルの購入状態も反映します。
- ダイス分布、倍率の端数処理、防御、HP4以下で50%の気絶、通常の余剰切り捨てとBoM-BeRの巻き込みを離席計算と共通の期待値モデルで扱います。巻き込み先ごとにも防御を適用。メタの防御無視・対象への特効・基礎攻撃力変更などは購入済みパークだけを参照します。
- 複数キャラは攻撃頻度の比率で平均化するため、実際の1秒周期の攻撃順と出目によって獲得量は前後します。DPS÷HPの単純換算は使いません。
- 一時停止中も再開時の見込みを表示。SPE中は有効中の性能で算出し、効果が切れたときに更新します。現在の敵HPや途中の行動点による一時的な偏りは含めません。
- 表示は小数第3位まで。計算は丸め前の値で行い、キャラの強化・パーク・セッション・コンセントレイション・スピードアップ・クリア報酬増加・オーバーキル・SPEの有無が変わったときだけ再計算します。攻撃ごとのHP変化や所持因子の増加では再計算しません。

### 行動力と行動点

- 行動力＝1秒ごとに増える行動点。ゲーム全体で共通の1秒刻みで、雇用済みキャラに行動力ぶんを加算します。
- 行動点100ごとに1回攻撃し、100点を消費。余りは持ち越します。250点なら2回攻撃して50点が残ります。
- 行動力が高ければ、同じ1秒の加算で何度でも攻撃できます。大量の攻撃には下記の一括計算を使用。
- 未雇用キャラは加算なし。初回雇用は0点から、次の共通周期で加算。一時停止中は加算周期も止まります。
- 強化ボタンの横に倍率と括弧内の単体DPS／秒間行動回数を表示。DPSはパーク・全体強化・限界突破・防御・追加攻撃の連鎖を含み、行動回数は行動点による攻撃回数（追加攻撃を除く）です。
- 行動力は `基本行動力 × (1 + 個別強化Lv × 0.1) × (1 + スピードアップLv × 0.01)`。全体強化なしのメタは個別Lv10で約111.11、スピードアップLv20もあれば約133.33です。
- 価格は `ceil(行動力基準費 × 1.15^強化Lv)`。メタの基準費は6Rd、リヒターは15Rd。威力とは価格・購入回数が独立します。
- 行動力を買うと周囲の丸鋸・爆弾が1個増え、次の加算から新しい行動力を使います。保有行動点・1秒周期の進み具合・ダイス・弾の大きさは変化しません。
- 基本行動力は従来の平均頻度を保つ値（メタは100÷1.8）。実際の攻撃タイミングは1秒刻みです。キャラの `action` と `balance.actionThreshold` で調整できます。
- 値はJavaScriptのNumberで保存。強化Lvは整数精度の限界（約9千兆）、通貨・累計は1e100まで検証します。これは数値表現上の制約で、Lv.200などのゲーム上の制限は付けていません。2^53以上の累計値は概数です。

### 大量の攻撃の計算

1回の更新で1200発を超える場合、個々のダイスを振る代わりに、現在の攻撃分布から「敵1体を倒す平均攻撃回数」を計算します。巻き込みパーク未解放時は敵ごとに余剰ダメージを切り捨てます。巻き込みを解放したリヒターまたはビシュナルを含む場合は、各HPから攻撃後のHPへの遷移と、巻き込み数・気絶・実際の与ダメージを計算した期待値モデルを使用します。途中まで削られた敵と最後の余剰分も進捗として引き継ぎます。複数キャラはその区間の実攻撃回数で重み付けするため、大量処理時の結果は期待値による近似です。

1秒周期の加算回数から獲得行動点と攻撃回数をまとめて計算し、ブースト終了時には区間を分けます。行動点・加算周期・残りHPの端数を次の更新へ引き継ぎます。少数攻撃は1秒周期・キャラの表示順にダイス判定します。短い連続攻撃ポーズは最後の射出動作が済んだ時点で途中のコマでも終了し、射出済みの弾と着弾演出は独立して最後まで再生します。行動力200以上（毎秒2回以上の自動攻撃）では、1秒周期の隙間でも連続モーションの再生を維持。一時停止・非表示・対象変更・読み込み時は解除し、低行動力で一時的に発生した連続攻撃や短い手動連打には延長を適用しません。

毎秒2回以上の自動攻撃では、各キャラの射出を1秒間へ均等に分散します（2回なら500ms間隔）。巻き込みの着弾は新たな射出として数えません。飛行時間は560msで、着弾判定の演出もその到着に合わせます。これにより1秒の初めに弾を出し切って残り時間に飛行表示がなくなる状態を防ぎます。極端な連射では引き続き回数付きの弾へ集約します。

### 手動攻撃の担当と撃破演出

- 雇ったキャラクターのカード（購入ボタン以外）をクリックすると、手動攻撃の担当になります。名前・顔の部分はキーボード操作にも対応。メタ・リヒターは戦闘画面の立ち絵からも選べます。
- 「攻撃する」は選択したキャラの現在の威力を使用。コンセントレイションはその固定値へ加算し、全攻撃倍率も適用します。行動点は消費せず、全員の自動攻撃は継続。
- 未選択では従来の「あなた」による1D6＋0（＋コンセントレイション）。「自分で攻撃に戻す」で選択を解除できます。雇用・強化ボタンでは担当は変わりません。
- 選択した担当はセーブ・JSON書き出しに保存。旧セーブは未選択から開始します。
- 丸鋸を短い間隔で順に射出し、各ヒットの着弾時に個別のダメージと残りHPを表示します。途中で撃破した場合は次の敵へ残りの攻撃を続行。撃破ごとに独立した敵のダウン動作を再生するため、先の敵が倒れている最中の撃破も省略しません。報酬・自動周回は即時処理し、演出時間は待ち時間に加算しません。
- 一時停止・セッション変更・セーブ読み込み・非表示時には、再生待ちの攻撃と各演出を解除。動きを減らす設定では動作を省き、集計ダメージとクリア・気絶ログを表示します。
- 敵のHPがダメージで1〜4へ減るたび、1D6で気絶判定。奇数なら気絶して戦闘不能、偶数なら続行します。4→3のように既に4以下から減った場合も再判定。HP0は判定なしで撃破、保存・読込や待機だけでは判定しません。気絶でも通常の報酬を獲得して自動周回し、残ったHPは与ダメージに数えません。
- 1,200回を超える一括処理では、各HPから撃破までの期待攻撃回数に50%の気絶確率を織り込んで、クリア・与ダメージを近似計算します。通常の余剰切り捨てと、BoM-BeRの巻き込みを区別します。画面上は極端な連射を最大12組の合計ダメージ・攻撃回数・撃破数に集約し、待ち行列やDOMが攻撃回数に比例して増え続けることを防ぎます。

### 鋼音メタの立ち絵と丸鋸

最初のキャラクターは、赤髪ボブ・黒セーラー服・赤ネクタイの【鋼音メタ】。
3頭身ほどにデフォルメした透過PNGのドット立ち絵を戦闘画面とキャラクターカードに表示します。
雇用前は薄く表示し、雇用後は自動攻撃に参加します。

- 雇用時は丸鋸1枚。行動力強化1回ごとに1枚増加し、威力レベルでは数を増やしません。リヒターの浮遊爆弾も同じ規則です。現在数を画面に表示。
- 威力Lvが高いほど、浮遊中・射出中の丸鋸と爆弾を大型化。表示倍率は `1 + log2(威力Lv) × 0.15`（Lv1で1倍、Lv10で約1.50倍、Lv50で約1.85倍）。個数が増えても縮小せず、サイズは威力Lvに依存します。周回する軌道の縦横径と輪同士の間隔も同じ倍率で拡大。表示中の個数に応じて軌道径を調整し、回転中のシンボルの実際の外周・キャラ本体・名前・敵の占有範囲から戦闘領域を決めます。未雇用のシンボル用スペースは確保しません。戦闘欄の幅・高さに収まりきらない場合は、敵・仲間・軌道・飛び道具をまとめて自動ズームアウト。HP・因子・操作ボタンは通常の文字サイズを維持します。
- 丸鋸が立ち絵の周囲を回転。メタの自動攻撃・選択中の手動攻撃で敵へ飛びます。2回攻撃なら2枚、3回なら3枚を少しずらして射出。
- 飛ぶ丸鋸は同時に120枚まで個別表示。空き枠を超える極端な連射は最大12本にまとめ、各丸鋸に「×回数」を表示します。通常の攻撃回数を間引くことはなく、合計回数とダメージは維持します。
- 表示上限は12枚から60枚へ拡大。1～12枚は1重、13～32枚は2重、33枚以降は3重の輪。交互に逆方向へ回転します。
- 61枚以降は最大60枚を代表表示し、総数は行動力の強化回数に連動します。実際の攻撃数・行動力にこの表示上限は適用しません。
- 既存の4コマPNGのうち、通常・攻撃の構え・腕を伸ばす3ポーズを使用。笑顔のコマは再生しません。待機中は落ち着いた表情で小さく上下に動きます。
- メタが同時に2回以上攻撃すると、白い三日月状のギャグ目で大口を開けて叫び、両腕が鞭のようにしなる細い半透明の軌跡になる専用3コマへ切り替えます。口には白い上歯、袖の色が見える残像の先には肌色を残し、先端の尖った白い斬線を添えています。コマ切替は60msごと。短い連続攻撃は最後の射出動作が済んだらコマの途中でも待機へ戻り、飛んでいる丸鋸・着弾・ダウンは継続します。毎秒2回以上の自動攻撃を続ける行動力では、周期をまたいで同じ連続モーションを再生します。通常のメタ2連続は約180ms、3連続は約300ms、5連続は約540ms。大量攻撃は表示をまとめ、次の射出がキューにあれば動作を維持します。280ms未満の手動連打も連続攻撃姿で再生。単発攻撃は従来の構え・射出ポーズです。
- 連続攻撃の3コマは外部PNG `img/meta-burst-v6.png`（672×224、1コマ224×224）。通常・構え・単発・連続攻撃を一枚の原画で描き直し、頭身・脚と靴の太さ・輪郭・陰影を統一しています。通常は1コマ128×160、連続攻撃は224×224をそのまま使い、1px単位の細かなドットで描画。身体の大きさと足元を合わせ、連続攻撃には軌跡の余白を確保。全状態に共通のPNGパレットを適用しています。旧素材は別ファイルで残しています。丸鋸の射出数は引き続き実際の攻撃回数から計算します。
- ダメージは既存のレベル成長式で計算。丸鋸の表示数で二重に倍率を掛けません。
- 一時停止・未雇用時は動きを停止。OSの「視差効果を減らす」にも対応。
- `js/data.js` の `metaVisual` から画像パス・表示上限を変更できます。輪の配置・コマ切り替えは `js/app.js` と `meta.css`。

### 鋼音メタの特性（パーク）

基礎攻撃力は2D6＋0。指定Lvに達した後、因子で個別購入します。費用は仮設定です。

| 攻撃力Lv | パーク | 解放費（仮） | 効果 |
| --- | --- | ---: | --- |
| 10 | メタルブレード | 10Rd | メタの判定が相手の防御を無視 |
| 20 | アタックプラス | 50Rd | 攻撃力＋4 |
| 30 | モヒカン死すべし、慈悲はない | 100Rd | [モヒカン]属性へのダメージ判定＋15 |
| 40 | フルメタルバースト | 250Rd | 攻撃力＋8 |
| 50 | メタルマン | 800Rd | 基礎攻撃力を4D6＋5へ変更 |

- メタルマンは基礎だけを置き換え、購入済みの＋4／＋8は加算。全購入時は4D6＋17です。モヒカン特効は対象への出目にさらに＋15してから倍率を掛けます。
- ダメージ順序：`max(0, floor((ダイス＋攻撃力固定値＋対象特効) × Lv倍率 × 連携・ブースト倍率) − 防御)`。メタルブレード購入済みなら防御を0として計算。端数は倍率を全部掛けた後に1回だけ切り捨てます。
- 自動・選択中の手動攻撃・DPS・離席中の期待値計算に適用。「あなた」の手動攻撃へキャラのLv倍率やパークは引き継ぎません。防御で0ダメージなら気絶判定も行いません。
- 敵の設定は `js/data.js` の各sessionの `defense`（非負の整数）と `traits`（属性ID配列）。モヒカン属性は `mohican`。現在のチーム世紀末覇者は防御0・モヒカン属性です。戦闘画面に防御と属性、対象外の特効パークに「解放済・対象外」を表示します。
- DPSは敵に対する各出目の端数処理・防御・特効を反映した期待値。敵HPでの余剰切り捨てや気絶による周回速度とは異なります。

### ゲルハムト・リヒターと特性（パーク）

現在のキャラクターは鋼音メタ、ゲルハムト・リヒター、右藤ビシュナルの3人。リヒターの雇用費100Rd、基礎行動力25（4秒ごとに1回）は調整用の仮設定です。

| 必要な攻撃力Lv | パーク | 解放費（仮） | 購入後の効果 | 全対象パーク購入時の攻撃式 |
| --- | --- | ---: | --- | --- |
| 1 | — | — | 基礎5D6＋0 | 5D6＋0 |
| 10 | Z-BoM. | 40Rd | 攻撃力Lv10につき＋1D6。購入後、Lv20なら＋2D6、Lv60なら＋6D6 | (6D6＋0) ×1.9 |
| 20 | DX-BoM. | 150Rd | 固定値＋8 | (7D6＋8) ×2.9 |
| 30 | VX-BoM. | 350Rd | 固定値＋16 | (8D6＋24) ×3.9 |
| 40 | EX-BoM. | 700Rd | 固定値＋24 | (9D6＋48) ×4.9 |
| 50 | BoM-BeR | 1,600Rd | 余剰ダメージが後続の敵を連鎖して巻き込む | (10D6＋48) ×5.9 |

- 指定Lvに達しただけでは効果なし。カードの「特性（パーク）」を開いて、因子で個別購入します。前段のパークを買うことは条件にせず、各パークのLv条件と費用で判定。購入済みパークは再購入不可。価格は js/data.js の各perk.costで調整できます。
- 通常成長は1Lvごとにダメージ倍率＋10%。購入したDX／VX／EXの固定値は累積（全部で＋48）し、出目にそのまま加えてから倍率計算を行います。行動力Lvは解放条件に含みません。Z-BoM.は一度購入すれば、その後の10Lvごとの増加に追加料金は不要です。
- パークは自動攻撃と、リヒターを選択した手動攻撃の両方に適用。メタには巻き込みは付与されません。
- BoM-BeR未購入の余剰は破棄。購入後、防御0のチーム世紀末覇者でHP10に43点なら10＋10＋10＋10＋3と伝わり、4体撃破して次の敵がHP7になります。ぴったり倒した場合は0ダメージの追加攻撃を行いません。
- 巻き込み先にも敵ごとに防御を適用。たとえばテスト用のHP40・防御2の敵なら1体につき42点を消費し、残りのダメージを次の敵へ渡します。巻き込み最後の端数にも防御を引きます。手動・自動・離席中の一括処理で共通です。
- 巻き込み先の残りHPが1〜4なら50%の気絶判定。気絶で残ったHPから新しい余剰ダメージは発生せず、各撃破・気絶に報酬を支払います。離席計算も購入済みパークだけを参照します。
- 立ち絵は黒い逆立ち髪・サングラス・厚い唇・茶色のロングコート・ピンクの襟元。頬の絆創膏はありません。待機→振りかぶり→投球→振り抜きの4コマ。手から離れる瞬間に外部PNGのピンク色の爆弾クリーチャーを射出し、弧を描いて傾きながら着弾します。巻き込み先にも爆発・ダメージ・ダウンを表示。
- メタ140cm・リヒター180cmを144px対185pxの身体高で反映（約9:7）。画像枠はメタ128×160、リヒター192×224で、枠の透明余白を身長には含めません。モバイルでは両方を同じ比率で縮小します。
- 外部透過PNG：img/richter-standing-v7.png（192×224）、img/richter-poses-v7.png（768×224、横4コマ）、img/richter-burst-v8.png（960×224、横4コマ）、img/richter-creature-v3.png（96×96）、img/richter-explosion-v1.png（768×128、横6コマ）。旧素材は履歴用に残し、画面からは参照しません。
- 購入済みパークIDをセーブ形式11のpurchasedPerksに保存。旧形式1〜6はパーク未購入で移行し、形式7は購入済みパーク・Lv・因子・行動点を維持したまま移行します。ホロウ・ジェイミーは画面・戦闘から削除し、旧セーブの該当レベル・行動力・行動点を除去。削除キャラを手動担当にしていた場合は「あなた」に戻します。所持因子・累計記録・メタとリヒターのレベルと行動点は維持します。

## セーブを移す

1. 移動前のゲームで「セーブ管理」→「ファイルに書き出す」。
2. フォルダや公開先を移し、移動先のゲームを開く。
3. 「セーブ管理」→「ファイルを読み込む」で書き出したJSONを選ぶ。
4. 因子・参加人数・周回対象・保存日時を確認し、「このデータを読み込む」。

「現在のデータを表示」でJSONをコピーし、移動先に貼り付けて確認・読み込みすることもできます。
ブラウザのサイトデータ削除や端末故障に備え、書き出したファイルはゲームのフォルダとは別にも保管してください。
ファイルは端末内で読み書きし、外部サーバーへ送信しません。

### 保存の設計

- 固定ゲームID：`yggclicker`。保存キー：`yggclicker.save`。フォルダ名やURLのパスを含めません。
- 同じオリジン（プロトコル・ホスト名・ポート）なら別のパスでも同じ進行を共有します。
- 異なるドメイン／ポート／ブラウザ／端末への移動は、書き出し・読み込みが必要です。
- `file://` の保存場所はブラウザ依存です。フォルダ移動前に必ず書き出してください。
- JSONには `gameId`, `schemaVersion`, `gameVersion`, `exportedAt`, `state` を格納。現在の形式は11。
- v0.1の形式1は自動移行。旧HP（80／400／2000）に対する残り割合を、新HP（10／40／150）へ切り上げ換算します。因子・雇用状況・強化・累計記録は維持します。
- v0.2以前の最初のキャラ（ID `hikari`）の雇用レベル・攻撃待ち時間は鋼音メタ（ID `meta`）へ自動移行します。v0.1→v0.3の連続移行にも対応。
- v0.5では旧レベルを威力Lvとして引き継ぎ、形式3から4への移行で `speedLevels` を0で追加。因子・待ち時間・記録は維持します。
- v0.6で形式4→5へ移行。旧 `speedLevels` を `actionLevels` へ、旧待ち時間の経過割合を `actionPoints` へ換算。新しい1秒周期 `actionClock` は0から開始します。旧形式1～4から段階的に引き継げます。
- v0.7で形式5→6へ移行。手動攻撃の担当 `selectedCharacterId` を未選択（null）で追加し、既存の進行を維持します。
- v0.12で形式6→7へ移行。購入済みパークを独立して記録し、削除キャラの旧IDを整理します。
- v0.22で形式8→9へ移行。オーバーキルボーナスを未購入（0）で追加し、既存の進行・設定を維持します。新形式を読めない旧アプリでは更新を促します。
- キャラ・セッション・強化は固定IDで参照。表示名やディレクトリ名は保存形式から独立。
- 追加キャラ／強化の不足IDは初期値で補完。未知のID・新しい形式は黙って捨てず拒否。
- 形式変更時は `js/save.js` のバージョンと段階的な移行関数を追加する。
- 数値の範囲・型・ゲームIDを検証。壊れたファイルの読み込みでは現在の進行を変更しない。
- 自動保存の前回分を `yggclicker.backup` に保持。最新が破損したら復元を試す。
- 両方破損したら自動上書きを止め、有効なファイルの読み込みを待つ。
- 読み込み前の進行は `yggclicker.before-import` に別途保持。自動保存では上書きしない。
- 保存不可・容量不足では警告し、プレイ中のデータを書き出せるようにする。
- 全データがブラウザ内にあるため、改変防止やオンラインランキングの信頼性は対象外。

- Lv到達だけでは発動せず、因子による個別購入が必要。追加攻撃率は購入済みの最大値を使い、加算しません。各パークは独立して購入できます。
- 追加攻撃は同じ攻撃式で毎発ダイスを振り直し、再び次の追加攻撃を抽選。自動・手動の両方で有効。追加の行動点・手動クリック回数は消費しません。コンセントレイションは自動・手動の追加攻撃にも適用。
- 抽選対象は発射した攻撃1回。巻き込み先への着弾で追加抽選やミサイルが増えることはありません。
- 連鎖込みの平均攻撃回数は1/(1−確率)。10%なら約1.111倍、25%なら約1.333倍、50%なら2倍。DPS・因子獲得見込み・限界突破コスト・大量処理・離席計算に反映。1発の威力にはこの回数倍率を掛けません。
- 通常規模の攻撃は幾何分布の逆関数で連鎖回数を抽選し、各ダメージ判定を実施します。ゲーム上の連鎖回数上限は置かず、乱数の無限ループも回避。大量処理は従来の期待値モデルを使用し、追加攻撃の平均回数も重み付けします。
- 通常4コマ（待機2・構え・発射）と乱射4コマは共通の外部透過PNG。表情を変えず、体とランチャーの反動・発射口の閃光で動きを付けています。乱射は最後の発射で終了し、毎秒複数発の自動攻撃が続く間は通常立ちに戻しません。
- ミサイルは各発射ごとに表示し、攻撃力Lvで大型化。着弾の汎用ヒット火花と爆発を併用。一時停止・タブ非表示・動きを減らす設定に対応。極端な攻撃回数は表示をまとめ、戦闘結果は維持します。
- セーブ形式11。旧形式10以前には未雇用のビシュナルを追加し、既存の因子・育成・戦闘進行を維持。新しいセーブを古いゲームで読み込む際はバージョン不一致として停止します。
