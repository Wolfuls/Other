# YggClicker v0.57.5

『鋼鉄のユグドラシル RW - Red Within -』の非公式二次創作・放置ゲーム試作。クエストごとに最大5人の部隊で同時に戦います。外部ライブラリ、CDN、ビルドは不要です。

## 起動・検証

Node.js 20以上で、このフォルダから実行します。

```sh
npm start
npm test
```

既定URLは `http://127.0.0.1:4173/`。ポート変更は `node tools/serve.cjs 4174`。`index.html` を直接開くこともできますが、保存はブラウザ依存です。ホスト・ポートを変える前にセーブを書き出してください。

## 活性と暫定調整値

| キャラクター | 活性 | 基礎暴走圧／秒 |
| --- | --- | ---: |
| メタ・ゲルハムト・ジュエル | 覚醒型 | 0.02 |
| ビシュナル・元加 枠 | 反応型 | 0.01 |
| トルデリーゼ・マックス | 回復型 | 0.005 |

指定された「ふつう／ややひくめ／ひくい」を上記の仮値に対応させています。覚醒型の固有効果はデータ定義枠のみで、個別効果は未設定です。

育成暴走圧は `0.01 × log2(1＋現在の育成Lv合計)`／秒。未編成・戦闘不能中は正の暴走圧を停止し、鎮静のみ適用します。因子安定化は初価20,000Rd・価格×1.5、1Lvで鎮静圧＋0.1／分。各パークの追加暴走圧は初期値0です。

50・60・70で活性が最大3段階、80・90でダメージ・命中・回避・SS・行動力の能力ロールに合計最大＋2D6。回復型は1段階あたり自然回復速度＋20%、正の暴走圧−10%です。

50・70・90・110・120・130・140・150を上方向へ通過すると対応するイベントを解決します。同じ閾値は10ポイント下まで戻ると再武装。症状は70未満で解除。臨界余力は正の増加を先に肩代わりします。臨界因子の換算率は暫定0、過負荷の自傷倍率は1です。

調整値は `js/data.js` の `strength`、`runtimeBalance`、`runawayThresholds`、`seedSystem`、各パークの `runawayPressure` に集約しています。

## 計算と保存

強度は `100 × 1.1^Lv`。攻撃は威力Lv−1、他の3種類は各育成Lv、敵は挑戦Lv−1を使います。比率は対数で計算し、表示・保存可能値の上限を設けています。命中・ダメージの強度指数は各1、オッズ変換前の確率クランプは1e−6です。

`js/strength.js` は特殊D6分布と逆算をキャッシュします。初回1は通常1D6を減算し、6の振り足しで出た1はファンブルにしません。無限のクリティカル末尾は22連続6まで列挙し、1e−18未満の経路を除いて正規化する、浮動小数点精度の数値計算です。ダメージは通常D6／D4を使用。貫通は防御値だけを0にし、防御強度は残します。

1秒AP処理と最大8時間のオフライン進行を維持。大量の単純攻撃は期待値による既存のまとめ処理を使用し、召喚・時限効果・暴走反応を伴う手番は個別に解決します。1秒あたり120手番を超える後者の処理は未消費APとして繰り越し、処理の省略や長時間の画面停止を避けます。通常のプレイ速度には影響しません。敵能力の被弾予測は固定シードの試行による概算で、気絶・自然回復を含む生存保証ではありません。

セーブ形式36。形式35からは鎮静調律を削除して旧購入費を一度だけ返還します。形式34からは因子安定化Lv0を補完し、既存の通貨・育成・暴走状態を保持します。通貨・育成・各部隊の戦況を引き継ぎ、旧パーク費の補償は `perkRefunded` で二重返還を防ぎます。暴走状態、無料切り替え、収入分類、未公開の種・カルマも保存します。将来形式のセーブは上書きせず、破損時はバックアップを確認します。
