## 計算と保存

味方の強度は `100 × (1＋0.02×(キャラクターLv−1)) × 1.08^(P/(1+2.5*P/C))`。行動力も同じ倍率を固定値補正後に適用します。敵の強度は `100×1.1^(挑戦Lv−1)`、敵行動力は `基礎行動値×1.1^(0.20×(挑戦Lv−1))` のままです。比率は対数で計算し、表示・保存可能値の上限を設けています。命中・ダメージの強度指数は各1、オッズ変換前の確率クランプは1e−6です。

HPは `floor(基礎HP × HP強度 / strengthBase)`。防御強度とは独立し、HPゲージと6秒ごとの最大HP1%回復は実際の最大HPを参照します。敵のHP強度Lvは他の強度と別の項目として算出します。

ダメージは 実強度値から `ratioLog=ln(攻撃強度/防御強度)` と `scaleLog=(ln(攻撃強度/100)＋ln(防御強度/100))/2` を用い、目標期待値を `max(1, 基礎期待値×exp(scaleLog＋ratioLog×damageStrengthExponent))` とします。対数空間で計算して1e100に制限し、実ロールへの整数補正に逆算します。絶対スケールを最終ダメージへ重ね掛けしません。

`js/strength.js` は特殊D6分布と逆算をキャッシュします。初回1は通常1D6を減算し、6の振り足しで出た1はファンブルにしません。無限のクリティカル末尾は22連続6まで列挙し、1e−18未満の経路を除いて正規化する、浮動小数点精度の数値計算です。ダメージは通常D6／D4を使用。貫通は防御値を0・防御強度を基準値100にして計算します。貫通無効では双方を保持します。

1秒AP処理と最大8時間のオフライン進行を維持。大量の単純攻撃は期待値による既存のまとめ処理を使用し、召喚・時限効果・暴走反応を伴う手番は個別に解決します。1秒あたり120手番を超える後者の処理は未消費APとして繰り越し、処理の省略や長時間の画面停止を避けます。通常のプレイ速度には影響しません。敵能力の被弾予測は固定シードの試行による概算で、気絶・自然回復を含む生存保証ではありません。

セーブ形式39。一括Lvは既存の `levels` に保存。個人配分は `concentration[キャラクターID]`。形式37からは旧6項目の投資額を同価格曲線で換算し、端数を返還して現在HP割合を維持します。個別Lv項目は現行セーブから除きます。形式36からは旧線形成長の最大HPに対する現在HPの割合を、新最大HPへ一度だけ移行します。この中間移行では旧育成値・戦闘不能statusを保持し、予約攻撃にも絶対スケールを補完します。形式35からは鎮静調律を削除して旧購入費を一度だけ返還します。形式34からは因子安定化Lv0を補完し、既存の通貨・育成・暴走状態を保持します。通貨・育成・各部隊の戦況を引き継ぎ、旧パーク費の補償は `perkRefunded` で二重返還を防ぎます。暴走状態、無料切り替え、収入分類、未公開の種・カルマも保存します。将来形式のセーブは上書きせず、破損時はバックアップを確認します。
