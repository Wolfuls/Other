情報拡張装置【ウールヴハム】 Windows v1.22
ZIPを展開して Ulfhamr.exe を起動してください。64bit Windows / WebView2 Runtime が必要です。
更新時は起動中のウールヴハムを終了してから新しい版を起動します。既存データの保存先は変更していません。
配布ページ・取扱説明書：https://wolfuls.github.io/Other/Ulfhamr/

ブラウザ・Windows v1.22 / Firefox v1.0.6 の更新
・「状態を調整」でSPE・カルマの残り回数を増減できます。正数は回復、負数は消費。0から設定上限までで、履歴・巻き戻しに対応します。
・INの候補にAE「強度感知」「集束」を追加しました。集束の応用技併用・1R1回の制限は継続します。
・検索中に入力欄を作り直さず、候補だけを更新します。日本語変換中は候補更新を待ちます。
・Windows版はすべての画面を基本ウィンドウの隣に開きます。「開く方向：左／右」で配置を切り替え、設定を保存します。
・引き出し上端の「独立ウィンドウへ ↗」で切り離せます。「基本ウィンドウの隣へ戻す」で戻せます。
・Windows版のオプションは基本ウィンドウのしおりへ移しました。

検証：Windows実機で左右切替・隣接表示・切り離し・戻す操作・オプション・日本語検索・IN候補を確認。
回数調整と巻き戻し、IMEイベント中の入力欄保持、画面内の配置は回帰テストで確認しました。
実際のIMEによるキー変換操作は未検証です。

REの行動候補からオーバークロック・供給・気絶／瀕死／即死復活バーストを除外しました。
