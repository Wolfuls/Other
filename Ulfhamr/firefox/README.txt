情報拡張装置【ウールヴハム】 Firefox v1.0.11 テスト版
配布ページ・取扱説明書：https://wolfuls.github.io/Other/Ulfhamr/

リコリスのタブを開き、「キャラクター」→「リコリスの盤面へ追加」で直接コマを追加します。
ZIPの保存・ドラッグは不要です。HP等とBP・活性・補正込みの能力値を渡します。
コマの「詳細を表示」を開くと「リコリスの相手コマを選ぶ」の候補になります。
追加処理中は重複送信を防ぎます。追加を確認できなかった場合は盤面を確認してください。
コマの値は作成時点のものです。常時自動同期ではありません。

導入：ZIPを展開し、Firefoxの about:debugging#/runtime/this-firefox から
「一時的なアドオンを読み込む」で manifest.json を選択してください。
更新：以前の展開フォルダのファイルを置き換え、拡張を「再読み込み」。
リコリスのタブも再読み込みしてください。拡張IDは変更していません。
未署名のため、Firefox終了時に一時読み込みは解除されます。恒久インストールには署名が必要です。
検証：ローカル模擬盤面へのファイル保存なしの追加、比較相手読込、重複・失敗処理を確認。
Firefox実機上でのリコリスとの通信は未確認です。

簡単更新（Windows）
最初の一度だけ、このZIPを普段読み込む固定フォルダに展開してください。
次回から新しい配布ZIPを、その固定フォルダの Update-Firefox.cmd にドラッグします。
同じ場所へ上書きし、更新前の内容を隣にZIPで保存します。
実行前に未登録の宣言を登録し、キャラデータはオプションからバックアップしてください。
完了後は about:debugging#/runtime/this-firefox の「再読み込み」を押し、リコリスも再読み込みします。
Firefox終了後の一時読み込みは引き続き必要です。署名申請・自動更新は保留です。

今回の更新（ブラウザ・Windows v1.19 / Firefox v1.0.5）
・1つの盤面バフに複数の補正項目を追加できます。有効切替・期間はバフ全体で共有します。
・生成コマのリソースは HP / PP / 暴走率 / 因子D / 行動値 / 情報。情報はキャラクター画面の自由記入欄です。
・総消費PP、SPE、カルマは生成コマの「使用状況」にまとめます。
・Firefoxの「リコリスと連携」で対象コマを確認すると、同時にチャットの通知先を記憶します。
・宣言登録／巻き戻し時に、変更前→変更後を記憶したチャットへ発言します。通知チェックで停止できます。
・リモコン同様の通常発言です。専用systemタグではありません。コマの値自体の反映は従来どおり別操作です。
・通知先変更、入力中の文章、未接続の場合は送信せず理由を表示します。自動再送しません。
・行動値は計算値のためコマへ反映する方向のみ。情報は双方へ反映できます。
・Firefox実機での通信は未検証。ローカル模擬テストで送信・入力保護・重複防止を検証しました。

Firefox v1.0.8：SPE・カルマの残り回数調整、INの強度感知・集束、日本語検索の入力改善。

REの行動候補からオーバークロック・供給・気絶／瀕死／即死復活バーストを除外しました。

今回の更新（ブラウザ・Windows v1.23 / Firefox v1.0.8）
・「この宣言を登録」を宣言のコピー・一覧ボタンの横へ移しました。
・行動選択は基本行動／応用技／AE／バースト／特殊武装／SPE／カルマ／消費アイテムの8枠。検索は各枠の候補を絞ります。
・宣言欄で命中・回避・SS・各攻撃のダメージ式・行動値と、選んだ探索技能の式を確認できます。
・Firefox版はリコリス右端のしおりから画面内パネルを開きます。上端をドラッグで移動、右下でサイズ変更。「畳む」でも宣言を保持します。
・Firefoxのツールバーアイコンでも開閉できます。別サイトで押すとリコリスを新しいタブで開きます。
・旧版の保存キャラとテーマを引き継ぎ、コマの操作対象はパネルのあるタブに固定します。
検証：モデル・UI処理82件とコマ連携・パネル・保存引き継ぎの模擬テストが通過。
実際のFirefox画面での検証は、画面操作ツールのブラウザURLポリシー非対応により未実施です。

今回の更新（ブラウザ・Windows v1.24 / Firefox v1.0.9）
・宣言した行動に関係する判定式だけを表示します。精神攻撃は応用技の構成にある「精神」から識別します。
・SPE／カルマ／消費アイテムを「その他」にまとめ、リスト内で区分けしました。
・技名を少し大きな太字にし、カテゴリを色とラベルで区別します。
・宣言一覧と宣言コピーはカテゴリ順。同カテゴリ内は追加順を保持します。
・既存の計算70件と今回の表示・検索・並べ替え処理の回帰テストが通過。今回の画面表示は実機未検証です。

今回の更新（ブラウザ・Windows v1.25 / Firefox v1.0.11）
・現在ステータス、コンディション／被ダメージ／状態を調整／オプション／次Rとタブ切替を上部に固定します。
・行動一覧で宣言Lv、創造PP、補正先を選び、その値で宣言へ追加できます。宣言欄での変更も引き続き可能です。
・Windows向けFirefox導入ガイドEXEを配布します。ファイルの配置・更新、旧版バックアップ、Firefox読み込み画面への案内とパスコピーに対応します。
・未署名版のため、最後の一時読み込みはFirefox上で行います。Firefoxを終了すると解除される仕様は変わりません。

自動起動：配布ページの導入・起動EXEから配置更新してリコリスを開けます。専用プロファイルに保存します。旧環境のデータはバックアップから復元してください。

今回の更新（ブラウザ・Windows v1.26 / Firefox v1.0.12）
・応用技と特殊武装を同じリスト内に区分して表示。旧特殊武装枠は死力Lvの入力欄に変更しました。
・行動一覧は「宣言一覧（暫定）」を表示し、登録・全宣言コピー・メモ・死力の入力は置きません。死力は行動選択側だけで指定します。
・コンパクト表示で隠れていた暫定一覧と関連判定式を表示します。判定がない場合は案内を表示します。
・対抗計算は主要項目を集約し、追加補正・相手の活性・詳細条件を折りたたみました。
・Firefox版はリコリスのウィンドウと前後関係を共有し、最前面固定を解除しました。
