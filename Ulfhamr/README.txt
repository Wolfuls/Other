配布ページ
このフォルダの index.html を開いてください。各版へのリンクと取扱説明書をまとめています。
GitHub Pagesでこのリポジトリを公開する場合の配置先：
https://wolfuls.github.io/Other/Ulfhamr/
この更新はフォルダへの組み込みです。リポジトリへのコミット・pushは別途行ってください。
Webページ内のリンクは相対パスです。

ブラウザ版
app.html で起動します。Web上で同じドメインを使う場合は以前の保存データを引き継ぎます。
file://でHTMLを直接開く環境では、ファイル名ごとに保存領域が異なる場合があります。
旧index.htmlの保存データがあれば、配布ページにバックアップボタンを表示します。
JSONを書き出してapp.htmlの「復元」で読み込んでください。元データは消去しません。
ブラウザ・Windows・Firefox拡張機能間の移行は「バックアップ」「復元」を使います。

Windows版
downloads/     Windows版 v1.28、Firefox版 v1.0.14、Firefox導入用EXE
64bit WindowsとWebView2 Runtimeが必要です。既存の保存先は維持しています。

Firefox版
firefox/manifest.json、または配布ZIPを展開したmanifest.jsonを、
about:debugging#/runtime/this-firefox の「一時的なアドオンを読み込む」で選択します。
更新後は拡張機能とリコリスのタブを再読み込みしてください。
現在は未署名のテスト版です。恒久インストールにはMozillaの署名が必要です。
拡張IDと対象サイトの権限は維持しています。

直接コマ追加
リコリスのタブを選び、「キャラクター」→「リコリスの盤面へ追加」を押します。
ZIPを保存・ドラッグする必要はありません。作成時点のステータスと能力値を反映します。
コマの「詳細を表示」を開くと「リコリスの相手コマを選ぶ」から選択できます。
模擬盤面での追加・相手読込、失敗処理、連打防止は検証済みです。
実際のFirefox・リコリス間での通信確認は未完了です。

データ処理
キャラシートと保存データは端末内で処理します。元のExcelは変更しません。
コマ追加・状態反映を押した場合のみ、選択したリコリスへデータを渡します。

簡単更新（Windows）
最初の一度だけ、このZIPを普段読み込む固定フォルダに展開してください。
次回から新しい配布ZIPを、その固定フォルダの Update-Firefox.cmd にドラッグします。
同じ場所へ上書きし、更新前の内容を隣にZIPで保存します。
実行前に未登録の宣言を登録し、キャラデータはオプションからバックアップしてください。
完了後は about:debugging#/runtime/this-firefox の「再読み込み」を押し、リコリスも再読み込みします。
Firefox終了後の一時読み込みは引き続き必要です。署名申請・自動更新は保留です。

今回の更新（ブラウザ・Windows v1.27 / Firefox v1.0.13）
・新規コマの暴走率・因子D・総消費PP・SPE・カルマを数値リソース、情報をノートとして出力します。
  SPE・カルマは有限回数の残りと上限の合計です。能力名・個別回数・常時効果等は内訳ノートに残します。
  上限を指定していない数値リソースの右側の値は出力時点の値です。必要に応じてリコリスで編集してください。
・SE/チャージを含む応用技はチャージLvを指定できます。元の技のPPに、Lv1を超える1Lvごとに2PPを加算します。
  創造PPとは別に指定し、宣言コピーと履歴にも記録。チャージ解放時の判定補正は盤面の補正へ登録してください。
・死力は今回の宣言の合計消費PPまで、かつHP消費で0未満にならない範囲まで（HP0ちょうどは可）。
・対抗判定は宣言から自分と相手の判定を自動選択。物理攻撃は命中対回避、通常回避は回避対命中、精神攻撃・回避はSS対SSです。
  相手の命中・回避・SSは別々に保持します。未取得の項目は入力を求め、他の判定値で代用しません。
・REの応用技はオート／セミオート／トラップを含むもののみ。連携バーストを追加すると他の応用技も候補になります。
  REの特殊武装はトラップボム・毒電波発生装置・アーマー・ワイヤートラップ・ブラックボックスのみ。連携バーストでは変わりません。
・REのバーストは判定・発動・連携のみ、AE/重撃は非表示。INのバーストは暴走のみ。
・AC/REの基本行動は1つの宣言につき1つ。ENにはオート／セミオート／トラップを含む応用技を暫定表示します。

今回の更新（ブラウザ・Windows v1.28 / Firefox v1.0.14）
・プルダウンにカーソルを合わせてホイールすると、候補を前後に切り替えます。
・死力による代用分を差し引いた実消費PPが現在PPを超える宣言は追加・登録できません。
  死力で支払える場合は、必要なLvとHP消費を示す「死力Lv…で追加」を選べます。
・SE/チャージの開始を登録するとカウント1で蓄積開始。応用技欄に「チャージカウント」と「チャージ完了」を追加します。
  宣言したチャージLvまでカウントを進めてから完了すると、カウント×3Dを命中（精神はSS）と攻撃の威力へ反映します。
  カウント・完了自体のコストは0です。バトル中は各々ACを使います。履歴の巻き戻しで蓄積状態も戻ります。
  v1.27までのチャージ補正の手動登録は不要です。
・比較欄の名称を「勝率」に変更。探索中は自分と目標の固定値・ダイス数を直接入力します。
  目標の初期値は8＋0D。固定目標は同値で成功、相手にもダイスがある場合は初期設定で同値ロールとして計算します。
  自分の判定は宣言した探索技能と補正から反映でき、手入力への切替も可能です。
・宣言中の応用技にある強化・減衰・追加などの補正量を、現在の精度と技構成から表示します。
  「盤面の補正へ登録」から対象・補正項目を確認して保存すると勝率や判定式にも反映します。
  対象技能が技構成だけでは分からない場合は登録時に指定します。性質・晩成など条件付きの固有処理は手動です。
