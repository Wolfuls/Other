情報拡張装置【ウールヴハム】 v1.19

構成
index.html     配布ページ・取扱説明書
app.html       ブラウザ版の起動ページ

配布ページ
このフォルダの index.html を開いてください。各版へのリンクと取扱説明書をまとめています。
GitHub Pagesでこのリポジトリを公開する場合の配置先：
https://wolfuls.github.io/Other/Ulfhamr/
この更新はフォルダへの組み込みです。リポジトリへのコミット・pushは別途行ってください。
Webページ内のリンクは相対パスです。

ブラウザ版
app.html で起動します。Web上で同じドメインを使う場合は以前の保存データを引き継ぎます。
file://でHTMLを直接開く環境では、ファイル名ごとに保存領域が異なる場合があります。
旧index.htmlの保存データがあれば、配布ページにバックアップボタンを表示します。
JSONを書き出してapp.htmlの「復元」で読み込んでください。元データは消去しません。
ブラウザ・Windows・Firefox拡張機能間の移行は「バックアップ」「復元」を使います。

Windows版
downloads/Ulfhamr-Windows-v1.19.zip を展開して Ulfhamr.exe を起動します。
64bit WindowsとWebView2 Runtimeが必要です。既存の保存先は維持しています。

Firefox版
firefox/manifest.json、または配布ZIPを展開したmanifest.jsonを、
about:debugging#/runtime/this-firefox の「一時的なアドオンを読み込む」で選択します。
更新後は拡張機能とリコリスのタブを再読み込みしてください。
現在は未署名のテスト版です。恒久インストールにはMozillaの署名が必要です。
拡張IDと対象サイトの権限は維持しています。

直接コマ追加
リコリスのタブを選び、「キャラクター」→「リコリスの盤面へ追加」を押します。
ZIPを保存・ドラッグする必要はありません。作成時点のステータスと能力値を反映します。
コマの「詳細を表示」を開くと「リコリスの相手コマを選ぶ」から選択できます。
模擬盤面での追加・相手読込、失敗処理、連打防止は検証済みです。
実際のFirefox・リコリス間での通信確認は未完了です。

データ処理
キャラシートと保存データは端末内で処理します。元のExcelは変更しません。
コマ追加・状態反映を押した場合のみ、選択したリコリスへデータを渡します。

簡単更新（Windows）
最初の一度だけ、このZIPを普段読み込む固定フォルダに展開してください。
次回から新しい配布ZIPを、その固定フォルダの Update-Firefox.cmd にドラッグします。
同じ場所へ上書きし、更新前の内容を隣にZIPで保存します。
実行前に未登録の宣言を登録し、キャラデータはオプションからバックアップしてください。
完了後は about:debugging#/runtime/this-firefox の「再読み込み」を押し、リコリスも再読み込みします。
Firefox終了後の一時読み込みは引き続き必要です。署名申請・自動更新は保留です。

今回の更新（ブラウザ・Windows v1.19 / Firefox v1.0.5）
・1つの盤面バフに複数の補正項目を追加できます。有効切替・期間はバフ全体で共有します。
・生成コマのリソースは HP / PP / 暴走率 / 因子D / 行動値 / 情報。情報はキャラクター画面の自由記入欄です。
・総消費PP、SPE、カルマは生成コマの「使用状況」にまとめます。
・Firefoxの「リコリスと連携」で対象コマを確認すると、同時にチャットの通知先を記憶します。
・宣言登録／巻き戻し時に、変更前→変更後を記憶したチャットへ発言します。通知チェックで停止できます。
・リモコン同様の通常発言です。専用systemタグではありません。コマの値自体の反映は従来どおり別操作です。
・通知先変更、入力中の文章、未接続の場合は送信せず理由を表示します。自動再送しません。
・行動値は計算値のためコマへ反映する方向のみ。情報は双方へ反映できます。
・Firefox実機での通信は未検証。ローカル模擬テストで送信・入力保護・重複防止を検証しました。
