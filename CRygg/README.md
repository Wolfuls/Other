# CR 鋼鉄のユグドラシル — v0.36

`index.html`をブラウザで開いて遊ぶ。画像やスクリプトは外部ファイルで管理し、同梱フォルダごと配置する。

- `assets/js/game.js`：抽選・玉・釘・風車・発射ハンドル
- `assets/js/monitor.js`：左の演出モニタとの同期
- `assets/js/panel.js`：遊技／オプションの切替
- `assets/css/style.css`：表示とレスポンシブ配置
- `assets/images/reels/`：使用中の図柄8枚、共通数字8枚（9は文字表示）
- `assets/images/ui/`：保留ダイス3状態

図柄2はユーザー添付画像を無加工で使用。旧図柄・参考画像33枚と旧単体HTMLを削除し、非表示の説明欄・更新処理・未使用CSSを整理した。

保存データは従来のキーを継続使用。過去のREADME・PROMPTは制作履歴として残している。

非公式のファンメイド・架空機種。物理挙動と確率は試作用。
