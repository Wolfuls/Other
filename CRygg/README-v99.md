# v0.99 漫画リーチ仮組み

`index.html`を開き、オプションの「漫画デモ」から成功／ハズレを再生する。変動中は終了後に選択。デモは持ち玉・当選数・RUSH状態を変更しない。

通常の図柄9リーチにも漫画演出を接続。明示的なデモ復活は従来の復活演出を優先する。抽選結果は演出開始前の結果を維持する。

対峙 → 振り上げ → 叩きつけ → 回避＋瓦礫 → 甘いなぁ → 武器変形 → スフィンクス俯瞰 → nextFrame。
成功：暗転 → 8コマ斬撃 → 8コマ崩壊 → 振り抜き → 既存大当たり。
ハズレ：暗転 → 通常の遊技映像へ復帰（RUSH中の抽選は既存の残回数処理を維持）。

実装は `assets/js/manga.js`、`assets/css/manga.css`。採用素材を `assets/images/manga/` にコピーし、制作元は `design/manga-reach/` に保存。既存SEを仮使用。

検証：JavaScript構文、既存の発射・入賞音／大当たり回帰テスト、専用Chromeで両モニタ同期・成功から大当たり・ハズレ後の後始末・デモ統計非加算・リセット中断を確認。
