# v0.38
- 都市背景にゆっくりした移動、霧の移動、窓明かりの明滅を追加。図柄は固定。prefers-reduced-motion時は停止。
- 独自合成の外部WAVを8本追加：抽選開始、左／中／右停止、リーチ、先バレ、大当たり、RUSH。
- オプションに音量スライダー。効果音OFFで再生中の音も停止。設定を保存。
- assets/js/audio.jsが再生を担当。tools/generate_sfx.pyで同じWAVを再生成可能。ネット接続不要。
- ブラウザが初回再生を制限する場合は玉貸し等の操作後に再生可能。読込失敗や再生拒否でゲームを止めない。
- WAVの長さ・クリッピング、各演出の音イベント順序、ブラウザでの読み込み・再生・消音・背景アニメーションを検証。
