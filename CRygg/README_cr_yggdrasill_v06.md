# CR鋼鉄のユグドラシル ― RAGNAROK ― v0.6

非公式・無料のブラウザ用パチンコシミュレーター試作。
v0.5をもとに、画像で指摘された液晶左下の滞留と、液晶に玉が隠れる表示を修正しました。

## 起動方法

ZIPを展開し、`cr_yggdrasill_prototype_v06.html` をブラウザで開いてください。
外部通信・外部ライブラリ・インストールは不要です。

## 変更内容

### 液晶左下の釘付近に玉がたまる問題

- 斜めの釘列と下部の千鳥状の釘列が近接・重複し、玉が抜けられない隙間を作っていました。
- 重複する斜めの釘列を整理し、下部を一つの千鳥状の配置にしました。左右の同じ構造に適用しています。
- 風車と周囲の釘の間にも、玉の直径に2pxを加えた隙間を確保しました。
- 滞留対策のために玉を消したり、強制入賞させたりする処理は追加していません。
- 既存の停滞時の補助処理と、13秒経過した玉をOUTにする上限処理は維持しています。

### 跳ねた玉が液晶に隠れる問題

- 盤面・釘用Canvasと、玉用の透明Canvasを分離しました。
- 玉を液晶より手前に描画するため、液晶の下から跳ね上がっても表示が隠れません。
- 両Canvasは同じ座標系・表示サイズを使用します。玉用Canvasは操作を遮りません。

## 検証結果

HTML内の実際の物理処理を、DOMとタイマーを代替したNode.js環境で検証しました。
乱数は固定シード、発射間隔は0.6秒、物理更新は120回/秒です。
入賞後の演出処理は停止させて、物理挙動を比較しています。

- 開き気味・標準・締め気味の3設定 × ハンドル30・50・70・90% × 各750玉。
- 旧版・修正版それぞれ9,000玉、合計18,000玉で比較。
- 赤枠相当の範囲（盤面座標 x=125〜200、y=490〜540）内で13秒の寿命上限を迎えた玉：旧版249玉 → 修正版0玉。
- 修正版でも、赤枠外で寿命上限を迎えた玉は計3玉ありました。盤面全体の滞留が完全にゼロになることを保証する試験ではありません。
- 赤枠の上から落とす42条件の試験：4秒後も赤枠内に残った条件は旧版18件 → 修正版0件。
- 全試験で発射数と「入賞数＋OUT数」が一致しました。
- 液晶下から上向きに跳ねた玉について、液晶領域内の43ステップで前面Canvasに描画されることを確認しました。Canvasの消去処理・描画順もコード上で確認しています。
- JavaScriptの構文確認は通過しています。

ブラウザでの実画面の目視確認は、確認環境の接続・操作制限により未実施です。
釘配置の変更に伴い入賞率は変わります。今回の標準釘の内部試験では約4.9〜8.4%でした。
